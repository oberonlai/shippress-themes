# Otonoha Acoustics

A quiet block theme for an architectural acoustic consultancy that measures rooms before finishes are specified. Diagonal-split first screen with a survey-day timeline, a drifting strip of room cards across a pale band, a sticky photograph beside four measurements, a report feed on a white sheet, and one graphite booking band. Hanken Grotesk and Onest; five languages (en, zh-TW, ja, fr, de) once localised.
