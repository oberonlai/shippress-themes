== Description ==

Otonoha Acoustics is an architectural acoustic consultancy theme designed for measuring rooms before interior finishes are specified. Built with an editorial sans-serif layout, documentary photography, and calm silver-slate tones, it presents technical surveys, report breakdowns, and clear fee schedules. Features a diagonal-split hero, sticky measurement guides, and seamless booking flows for independent acoustic practices.

The home page opens on a diagonal split: a pale upper half with the staggered headline, a dark low-key photograph of an empty auditorium below a rising seam with the second line in white, the outline booking pill and a five-tick survey-day timeline. It continues with four square room cards drifting sideways across a pale band, a three-line approach heading beside two columns of text, a tall photograph that stays in view beside four measurements, the report feed on a white sheet that runs off the right edge, a parallax hall band, three case notes, the fee table, how booking works and a graphite band with the single Book a room survey pill. The footer carries the survey-calendar sign-up, which uses the optional ShipPress form slot and needs no plugin.
