# Kama Cookware

A calm block theme (type store) for a cookware shop with a repair and seasoning workshop. WooCommerce-ready; works without it. Home page and plain inner pages (English) in this release; fuller inner pages and other languages follow.

## Signature
- Staircase hero: five 2.1:1 product photos, spaced apart and tone-matched to the pale stage, in a rising diagonal, a vertical caption rail and a slim info bar.
- Sticky half-width picture column that swaps through a mask reveal as each hob scene passes.
- One dark service band with six 3:4 frames that zoom in; giant wordmark marquee with photo pills in the footer.

## Patterns
- `header-split`, `footer-main`
- `home-hero`, `home-question`, `home-which`, `home-featured`, `home-service`, `home-prices`, `home-parallax`, `home-people`, `home-journal`, `home-visit`

## Fonts
Fraunces and Source Sans 3 (SIL OFL 1.1, licences in assets/fonts).

## Images (AI-generated for this theme, no text or logos; assets/images/)
P01–P21 (.webp), t1–t3 (footer pills), notes use assets/images/demo/.

## Header
Split navigation on wide screens; below 782px all six links sit behind the menu button. Menu links point to Shop, Which pan, Care, Repair, Journal and Visit pages created by the demo import.
