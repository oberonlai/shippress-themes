Kama Cookware is an asymmetric-masonry WordPress theme crafted for durable cookware stores and workshop services. Designed with a calm serif aesthetic, high-key photography, and smooth editorial scroll effects, it pairs WooCommerce shop capabilities with dedicated pan repair and care guides. Built for longevity, clarity, and dependable kitchen storytelling.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes) for a cookware shop with a repair and seasoning workshop. The home page opens on a pale stage where five product photographs climb a rising diagonal, followed by a question statement, a sticky half-width picture that changes with each hob scene, offset product cards, a single dark service band, fixed service prices, a parallax shop interior, people rows, journal rows and the visit block. A giant wordmark marquee closes every page. See brand.md and brand/design-spec.md for the design notes.

== Installation ==

1. Download kama-cookware.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kama-cookware.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kama Cookware.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, plain inner pages, three journal posts and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The shop, its people, addresses, prices and dates are fictional.
