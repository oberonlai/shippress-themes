# Kataribe Partners

Kataribe Partners is a calm, longform landing WordPress theme designed for public-relations agencies and sector communication studios. Built around a horizontal-strip archetype with high-key documentary photography and clean sans typography, it presents structured coverage weeks, transparent retainers, and live coverage logs. Features five-language compatibility, a short top menu to the inner pages and in-page anchors on the home page, and a single repeated call to action to request a proposal.

## Structure
- `patterns/front-*.php`: the nine home sections (hero with docked card, intro, fit cells, coverage strip, figures band, stories, retainers, people, request band); `head-bar.php` and `foot-main.php` are the header and footer.
- `templates/`: front page, page, single entry, news list, archive, category, tag, search and 404.
- `inc/i18n/<lang>.php`: the theme strings; `demo-content*.json`: sample content.
- Photos: `assets/images/` (AI-generated, GPL-2.0-or-later / CC0). See `readme.txt` for the list.
- Scroll effects: `assets/sp-scroll.css`, `assets/sp-scroll.js`.

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
