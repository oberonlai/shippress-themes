Kataribe Partners is a calm, longform landing WordPress theme designed for public-relations agencies and sector communication studios. Built around a horizontal-strip archetype with high-key documentary photography and clean sans typography, it presents structured coverage weeks, transparent retainers, and live coverage logs. Features five-language compatibility, a short top menu to the inner pages and in-page anchors on the home page, and a single repeated call to action to request a proposal.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download kataribe-partners.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kataribe-partners.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kataribe Partners.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, five news entries with two categories and five tags, the top menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. WooCommerce is supported but not needed.

Languages: the sample content comes in English (demo-content.json), and Traditional Chinese, Japanese, French and German (demo-content.zh-TW.json, .ja.json, .fr.json, .de.json). The importer uses the `shippress_demo_lang` option (set by ShipPress from its interface language), else the site language.

Scroll effects: assets/sp-scroll.css and assets/sp-scroll.js (a small script loaded in the head, no libraries). Content stays visible without JavaScript and with reduced motion.

The studio, its people, address, telephone number, figures and prices are fictional.
