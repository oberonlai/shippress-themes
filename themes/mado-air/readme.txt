Mado Air is a minimalist WordPress landing theme crafted for a compact home air purifier. Designed around natural-light photography, quiet typography, and clear technical specifications, it presents product features and pre-order details with calm restraint. The single-page conversion layout supports multilingual content and provides a distraction-free experience for modern domestic hardware.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download mado-air.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/mado-air.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Mado Air.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, the menu, and sets the front page.

Mado Home Studio, the Mado Air purifier, its people and its prices are fictional.
