Shiki Linen is a block theme for a bed-linen shop founded in Galway in 2014, with six washed cloths, three weaves and pieces cut to order. Prices are in EUR, from a €6 swatch set to bed sets, with WooCommerce templates for shop, product, cart, checkout and account. The sample pieces still show when WooCommerce is not active.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download shiki-linen.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/shiki-linen.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Shiki Linen.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, one journal article with a category and five tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. With WooCommerce active it also adds six sample products with five categories and five tags (inc/woo-import.php); without WooCommerce the theme works as a plain site.

The shop, its pieces, address, telephone number and prices are fictional.
