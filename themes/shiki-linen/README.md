# Shiki Linen

A WooCommerce store theme for a small bed-linen shop. Version 1.0.0 (home page, English).

- **Look:** pure white gallery ground, ink `#0D0E0B`, flax band `#F7F4EC`, moss `#5F6B4E` for the stitch and spec tags only. Manrope 200 headings, Source Sans 3 body.
- **Home:** hero (three equal framed photographs, parallax 6%), intro, weaves staircase (T2), wash-gradation strip (T1), spec catalogue, order stages, parallax washroom (10%), pieces pair, price list, ring close. The running stitch (T3) links the white voids.
- **References:** hadawa.jp (layout rhythm, strip, staircase, photo entrance) and terada-knit.co.jp (thread line). See `brand/reference.md` and `brand/reference-tokens.md`.
- **Motion:** `assets/sp-scroll.css` / `.js` only (zoom 1.06 to 1 at 0.5 s, stagger, wipe, parallax). Reduced motion and no-JS show the final state.
- **Templates:** front page, page, wide page, single, archive, category, tag, search, 404 and the WooCommerce shop, product, cart, checkout, account and order confirmation.
- **Patterns:** `front-hero`, `front-intro`, `front-weaves`, `front-gradation`, `front-catalogue`, `front-order`, `front-washroom`, `front-pieces`, `front-prices`, `front-close`.
- **Header:** centred wordmark, nav left, 'Order swatches' button and cart right (button hidden under 782 px). With WooCommerce active the hooked mini cart replaces the static cart link and the button goes to the Swatch set product; without it the cart link opens the shop page and the button opens Made to order.
- **Photos:** 18 film-grain photographs, each used once on the home page; the washroom, folding and hopsack photos show plain sheets only.
