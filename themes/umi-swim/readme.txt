Umi Swim School is a calm, accessible WordPress theme created for swimming schools, private pools, and aquatic instructors. Built with clean sans typography, soft water-inspired shapes, and dedicated timetable layouts, it presents course schedules, coaching profiles, and term fees with understated clarity. The theme includes block patterns for day schedules, programme tabs, and documentary photography to welcome learners of every age.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download umi-swim.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/umi-swim.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Umi Swim School.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, the menu, and sets the front page.

The school, its coaches, address, telephone number and prices are fictional.
