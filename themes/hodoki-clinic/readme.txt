Hodoki Clinic is a WordPress block theme for a physiotherapy clinic that treats desk workers and people after surgery. The copy follows one Fernhill practice, founded in 2015 by Clara Mendes, with the clinic's hours, seven visit prices, and seven named therapists. English, Traditional Chinese, Japanese, French, and German are included, and the theme is WooCommerce-compatible.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes).
