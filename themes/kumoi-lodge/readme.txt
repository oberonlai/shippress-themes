Kumoi Lodge is a calm, editorial WordPress theme designed for high-altitude lodges, alpine refuges, and quiet retreats above the weather. Built with refined typography, tactile framed layouts, and booking-led page structures, it provides an authentic digital home for small-scale hospitality. The theme presents room availability, seasonal schedules, and clear rates without requiring complex plugins.

== Description ==

Kumoi Lodge is a calm, editorial WordPress theme designed for high-altitude lodges, alpine refuges, and quiet retreats above the weather. Built with refined typography, tactile framed layouts, and booking-led page structures, it provides an authentic digital home for small-scale hospitality. The theme presents room availability, seasonal schedules, and clear rates without requiring complex plugins.

Fonts: Fraunces, Nunito Sans, Noto Serif TC and Noto Serif JP (SIL Open Font License 1.1), bundled. Photographs were generated for this theme. The scroll effects (sp-scroll) respect the visitor's reduced-motion setting and stay visible without JavaScript.
