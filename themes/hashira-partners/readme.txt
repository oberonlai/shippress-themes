Hashira Partners is a small-warehouse leasing brokerage in Port Merrin, founded in 2014. The site presents six buildings and 50 bays from 90 to 420 m², and takes viewing requests for Eastgate, Riverside and Mill Cross. Office hours are Mon–Fri 08:30–17:30, and viewing hours are Tue–Sat 09:00–15:00.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page opens on a black first screen with a two-line headline locked between three full-width rules, then runs through a statement, a looping line, three full-height case photographs with four caption columns, a stepped-bar buildings archive, five ruled viewing steps and one request form. See README.md for the design notes.

== Installation ==

1. Download hashira-partners.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hashira-partners.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hashira Partners.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The firm, its buildings, people, address, telephone number and fees are fictional.
