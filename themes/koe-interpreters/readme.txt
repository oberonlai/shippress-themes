Koe Interpreters is a calm, photographic WordPress landing theme designed for conference interpreting agencies, multilingual summits, and diplomatic meetings. Featuring documentary photography, refined typography, and deliberate editorial pacing, it presents services, booths, and transparent daily rates with professional clarity. Built with full block support and five-language readiness, it guides organizers smoothly from initial brief to on-site delivery.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes.

== Installation ==

1. Download koe-interpreters.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/koe-interpreters.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Koe Interpreters.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, five notes and stories with two categories and seven tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The agency, its people, address, telephone number and prices are fictional.
