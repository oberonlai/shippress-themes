# Shitsurae Interiors

Portfolio theme for an interior design studio. Home: caption-strip hero (full-bleed photograph, white strip under it with the project name and a loop ring), results-first case rows (three photographs of different sizes, 3 2 1 caption, budget), sticky works index with a two-column grid, material strip, ruled process rows, one dark booking band and a text-row journal. Fonts: Urbanist and Public Sans. Brand and design notes in `brand.md` and `brand/`.

## Status
Stage 2 (English) delivers the home page and the inner pages: Cases, Works, Process, Fees, Materials, Studio, Consultation, Contact, Newsletter, the Journal list, category and tag archives and one article. The zh-TW, ja, fr and de localisations follow in the language step. `screenshot.png` is a 1200x900 capture of the home first screen.
