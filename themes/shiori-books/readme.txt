Shiori Books is a block theme for an independent neighbourhood bookshop, set up for a shop that sells new, second-hand and rare books and holds a Saturday reading. It styles a WooCommerce catalogue and still works as a reading site when WooCommerce is not active. The front page is a day-and-evening entrance, a shelf index, a reading programme, the people of the shop, a price list and a visit panel.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download shiori-books.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/shiori-books.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Shiori Books.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, journal entries with categories, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The shop, its people, address, telephone number and prices are fictional.
