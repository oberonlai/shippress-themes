Komugi School is a quiet, editorial WordPress theme created for professional bakery schools and vocational culinary workshops. Built around structured daily schedule lists, hairline course registries, and documentary imagery, it delivers a calm, print-inspired aesthetic for modern kitchen education. The theme includes full block-editor support, Fraunces serif typography, and clear responsive layouts.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download komugi-school.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/komugi-school.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Komugi School.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php, driven by demo-content.json): it creates its pages with all their text and images, sample posts with categories and tags, the menu, and sets the front page and posts page. Then you only change the text and swap in your own pictures. It never changes or deletes existing content, and running it again only adds what is missing. If the automatic setup did not run, use the "Import demo content" button shown in wp-admin, or run: wp shippress demo-import
