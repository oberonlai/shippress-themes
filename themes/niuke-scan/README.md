# Niuke Scan

Niuke Scan is a single-column landing-page theme for small warehouse docks using the N1 handheld scanner and Count Sheet app. Built around documentary photography, clean typography, and quiet receiving workflows, it helps goods-in teams verify every carton at the door before shelving.

## Structure
- `patterns/front-*.php`: the nine home sections (hero, why, shift, product, spec, pricing, stories, faq, close).
- `parts/`: header (split nav with anchors and one pill) and footer.
- Inner pages (demo content): how-it-works, scanner, pricing, stories, about, setup, contact, waitlist (trial request), thanks, privacy, terms — all linked from the menu, CTAs and footer.
- `templates/`: front-page plus basic index, page, single, archive and 404.
- `assets/sp-scroll.css`, `assets/sp-scroll.js`: ShipPress scroll effects (parallax, reveal, stagger, mask), loaded in the head.
- Photos: `assets/images/` (hero 1920 px wide; the scanner is shown phone-sized, held, cradled and in use) (AI-generated, GPL-2.0-or-later / CC0). See `readme.txt` for the list.

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
