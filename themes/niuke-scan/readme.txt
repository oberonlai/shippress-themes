Niuke Scan is a single-column landing-page theme for small warehouse docks using the N1 handheld scanner and Count Sheet app. Built around documentary photography, clean typography, and quiet receiving workflows, it helps goods-in teams verify every carton at the door before shelving.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download niuke-scan.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/niuke-scan.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Niuke Scan.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images and sets it as the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The company, the N1 scanner, the Count Sheet app, the people, addresses and prices are fictional.
