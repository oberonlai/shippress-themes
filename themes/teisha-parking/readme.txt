Teisha Parking is a calm, focused WordPress landing theme designed for monthly car park operations. Built around low-key documentary photography, structured ledgers, and clear bay management, it offers drivers a dignified, transparent way to reserve dedicated parking. Every detail emphasizes unhurried clarity, legible fee schedules, and personal site-walk appointments.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download teisha-parking.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/teisha-parking.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Teisha Parking.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, three drivers' notes with a category and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The company, its people, address, telephone number and prices are fictional.
