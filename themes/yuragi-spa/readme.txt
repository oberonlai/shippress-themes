Yuragi Spa is a quiet, booking-led WordPress theme created for day spas, bathhouses, and hospitality retreats. Rooted in Japanese-inspired minimalism and natural film photography, it features sticky treatment lists, generous letterbox imagery, and serene typography. The unhurried layout guides visitors through private rooms and treatments with absolute clarity.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download yuragi-spa.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/yuragi-spa.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Yuragi Spa.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The spa, its people, address, telephone number and prices are fictional.
