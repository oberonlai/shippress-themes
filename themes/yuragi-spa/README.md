# Yuragi Spa

Yuragi Spa is a quiet, booking-led WordPress theme created for day spas, bathhouses, and hospitality retreats. Built on quiet, Japanese-inspired minimalism and natural film photography, it features sticky treatment lists, generous letterbox imagery, and serene typography. The unhurried layout guides visitors through private rooms and treatments with absolute clarity.

## Structure
- `patterns/home-*.php`: the ten home sections (hero with information bar, intro, treatment names, treatments, letterbox, booking, people, season, notes, visit).
- `patterns/inner-*.php`: reusable inner-page parts (page head, photo and text, text row, letterbox band, price table, questions, closing line).
- `templates/`: front page, index, page, wide-page (carries the ten inner pages), posts page (`home`), archive, search, single post and 404.
- `assets/sp-scroll.css`, `assets/sp-scroll.js`: the shared scroll effects (reveal up, looped marquee, photo parallax).
- `demo-content.json`: sample content in English (home, ten inner pages, the Journal page, one article, main menu).
- Photos: `assets/images/` (AI-generated, GPL-2.0-or-later / CC0). See `readme.txt` for the list.

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.

License: GPL-2.0-or-later.
