Kaname Watches is a calm, horizontal-strip WordPress theme designed for curated watchmakers and boutique stores requiring WooCommerce support. Built around a framed two-pane hero window, low-key photography, and alternating long-form editorial layouts, it presents timepieces with quiet precision. Clean Hanken Grotesk and Onest typography paired with bespoke service tables ensure an unhurried, tactile shopping experience.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download kaname-watches.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kaname-watches.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kaname Watches.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The sample content is read from demo-content.json.

The shop, its watches, address, telephone number and prices are fictional.
