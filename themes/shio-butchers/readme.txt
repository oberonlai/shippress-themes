Shio Butchers is a calm, photographic WordPress store theme crafted for independent butcher shops and whole-carcass craft counters. Built with clean editorial typography in Schibsted Grotesk and Albert Sans, it features ruled category index rails, brass corner tabs, and a structured day schedule for pickup orders. The theme supports pickup workflows, newsletter announcements, and optional WooCommerce integration with radius-zero brass styling.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download shio-butchers.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/shio-butchers.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Shio Butchers.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, journal entries with a category and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

Forms: the Saturday list section uses a small dynamic block (inc/shippress-forms.php). With MailPoet or Mailchimp for WP configured it shows that form; without a plugin it shows a real email field and a button that opens your email app with the address (nothing is subscribed until the email is sent). The order page uses Contact Form 7 or WPForms when present, else an email button. Recommended Contact Form 7 fields: name, email, phone, pickup day, cuts and weights, notes.

The shop, its people, address, telephone number, farms and prices are fictional.
