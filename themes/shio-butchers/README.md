# Shio Butchers

A calm, photographic block theme for an independent butcher shop (store type; WooCommerce optional).

Home: utility bar, ruled "This morning's cuts" rail beside a horizontal photo strip with a paper catch-line panel, brass TODAY-tab square cards, a day schedule, a parallax salt-block band, wrapping steps, farm cards, an order band and the Saturday list.

Signature techniques: ruled index rail, brass corner tabs, double-line button with a long arrow. Fonts: Schibsted Grotesk and Albert Sans. See brand.md and brand/design-spec.md.

## Shop
Store type with WooCommerce optional: `archive-product` and `single-product` templates wrap the WooCommerce legacy templates, and the demo ships five sample products priced per kilo. Without WooCommerce the shop pages are unused; orders go through the pickup order page, phone or email.

## Notes
The hero strip is a three-photo stagger (a 320px lead photo, then a taller and shorter neighbour, with paper rectangles on the seams) so the second photo and a paper block already show on a 1280px first screen. Arrow buttons are white at 85% opacity with a 1px ink border so they read on dark photographs.
