Sekisan Partners is an independent building cost consultancy WordPress theme crafted for precise commercial presentation and clear project budgeting. Designed around an architectural split-screen layout with an ink framing rail and bold index typography, it guides prospective clients smoothly from early concept estimates to formal proposal requests. Built for longform clarity, the theme delivers dependable performance across all screen sizes.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes and patterns.

== Installation ==

1. Download sekisan-partners.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/sekisan-partners.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Sekisan Partners.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page, ten inner pages (request, about, method, fees, cases, cost letter, notes, privacy, terms, thanks), one note with its category and featured image, and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The consultancy, its address, people, cases and fees are fictional.
