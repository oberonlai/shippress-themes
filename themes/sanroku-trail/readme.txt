Sanroku Trail Series is a calm, content-focused WordPress theme designed for mountain running events, seasonal race series, and outdoor athletic organisations. Inspired by documentary photography and landscape publication design, it features split typography, structured race ledgers, course aid accordions, and mandatory kit tables. Built for seamless storytelling, the theme pairs lightweight styling with precise editorial rhythm to showcase courses, logistics, and trail stewardship.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page opens on a film-grain photograph flush to the viewport with a vertical headline in the sky and the season's four races as ruled rows directly under it. Below: a story in three paragraphs, a horizontal season strip with scroll-snap, a dark olive band with a hairline course outline and an aid-station accordion with dotted leaders, an inset photograph with a six-cell mandatory kit table, a horizontal ribbon-day milestone row, a parallax valley band, a full-width fee ledger with the four steps to enter, and the journal with a newsletter row. Scroll effects (rise, zoom, stagger, parallax) use the small sp-scroll script in assets/ and respect prefers-reduced-motion. The optional newsletter and contact slots work without any plugin and use Contact Form 7, WPForms, MailPoet or Mailchimp for WP when present.

== Installation ==

1. Download sanroku-trail.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/sanroku-trail.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Sanroku Trail Series. On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): the home page, the inner pages (races, course guides, mandatory kit, enter, about, contact, newsletter), the journal with sample posts and the menu. Use Tools > Import demo content to run it again.
4. Edit everything in the block editor; the sections are block patterns in the "Sanroku Trail Series" category.

The series, its people, the valley, addresses and fees are fictional.

== Forms ==

Contact and entry enquiries: recommended Contact Form 7 fields are name (required), email (required), race (select: Snowmelt 21, Beech Line 32, Gorge 45, Autumn Ridge 60, Not sure yet) and message (required). Without a plugin the page shows an email button that opens your email app. The newsletter row always shows an email field and a submit button; without a mail plugin it opens your email app with the request and says clearly that you are not subscribed yet.
