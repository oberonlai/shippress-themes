Tochi Academy is an editorial WordPress theme designed for evening adult colleges and professional licensing academies. Styled with classical serif typography, delicate hairline circle motifs, and documentary photography, it provides comprehensive cohort schedules, week-by-week syllabus timelines, and transparent fee tables. Built for quiet legibility and disciplined academic presentation, it supports small-cohort vocational institutions balancing classroom learning with working life.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page opens on a huge white disc with one hairline arc that carries a "this term" photo slider, under a centred menu with a stacked exam-date stamp and a light caps ticker. Below it: bordered cards that overlap their photographs with a vertical date, a horizontal 24-week timeline, a parallax evening-classroom band, a deep green exam-sitting band, dashed-rule faculty rows and a full-width fees table. Scroll effects (heading wipes, card rise, counting figures, parallax) use the small sp-scroll script in assets/ and respect prefers-reduced-motion. The optional newsletter and contact slots work without any plugin and use Contact Form 7, WPForms, MailPoet or Mailchimp for WP when present.

== Installation ==

1. Download tochi-academy.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/tochi-academy.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Tochi Academy.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page, the journal page with sample posts and the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works without WooCommerce.

The college, its people, address, telephone number and prices are fictional.
