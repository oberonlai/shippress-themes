Kairo Supply is a photographic block theme designed for electrical wholesalers and trade counters. Built around a hairline grid, documentary photography, and structured trade account onboarding, it presents stocked ranges, cutting bay services, and contractor accounts with calm precision. Engineered for clarity and fast navigation, the theme delivers responsive tables, accessible typography, and purpose-built block patterns.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes and patterns.

== Installation ==

1. Download kairo-supply.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kairo-supply.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kairo Supply.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page, the inner pages, the Notes page and one article with all their text and images and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The trade counter, its address, telephone number and prices are fictional.
