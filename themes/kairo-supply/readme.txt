Kairo Supply is a purposeful WordPress theme designed for electrical wholesalers and trade counters serving professional contractors. Built with a sticky-media layout, clear trade account workflows, and industrial daylight aesthetics, it presents stock numbers, counter services, and rate schedules with calm precision. The theme provides complete multi-language support, custom block patterns, and fast-loading documentary imagery tailored to commercial supply businesses.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download kairo-supply.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kairo-supply.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kairo Supply.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page and the menu with their text and images, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The company, its people, prices and telephone number are fictional.
