Hiroba Food Hall is a serene, serif-led WordPress theme designed for food halls, shared markets, and multi-kitchen dining spaces. Built around a structured weekday lunch schedule, it features framed window galleries, communal table booking workflows, and responsive kitchen showcases. With full block editor support and refined editorial typography, it presents daily dining with warmth, clarity, and precision.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download hiroba-food-hall.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hiroba-food-hall.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hiroba Food Hall.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, four guest notes with four categories and six tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works as a plain site without WooCommerce.

The hall, its kitchens, people, address, telephone number and prices are fictional.
