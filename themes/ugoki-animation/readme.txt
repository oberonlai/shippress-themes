Ugoki Animation is a minimalist portfolio theme crafted for independent animation studios, directors, and craft-led ateliers. Inspired by editorial archives and digital atelier aesthetics, it features an inset dark window hero, key-drawing marquee strip, credit-ledger case walls, and contact-sheet project pull-backs. Designed for the WordPress block editor with quiet typography, film-grain imagery, and responsive frame-accurate layouts.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes.

== Installation ==

1. Download ugoki-animation.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/ugoki-animation.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Ugoki Animation.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The studio, its people, clients, address, telephone number and prices are fictional.
