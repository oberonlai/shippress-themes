School excursion and study-trip organiser WordPress theme for educational travel agencies, schools, and teachers. Built with an editorial split hero, timed story rails, audience gateway cards, and term-by-term planning timelines. Features clean typography with Source Serif 4 and Nunito Sans, structured itinerary layouts, and calm, accessible design.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download tabidachi-tours.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/tabidachi-tours.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Tabidachi Study Tours.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with their text and images, journal entries with categories and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

Forms: The Register section uses a dynamic form block (inc/shippress-forms.php). Without a form plugin it shows an email field and a submit button that opens your mail program with the address filled in (the visitor is not subscribed until the message is sent). With MailPoet or Mailchimp for WP it shows that form instead.

The organiser, its trips, people, address and prices are fictional.
