Naru Clinic is an occupational health WordPress theme designed for workplace health providers, industrial clinics, and ergonomic assessors. Built for clarity and practical patient guidance, it features structured assessment workflows, transparent service pricing, and calm, accessible layouts. Clean typography and responsive block templates ensure workers and managers find essential health information effortlessly.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download naru-clinic.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/naru-clinic.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Naru Clinic.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice. Works without WooCommerce.

The clinic, its people, address, telephone number and prices are fictional.
