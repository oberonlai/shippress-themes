# Kuruma Tabi

A ShipPress block theme for private chauffeured sightseeing tours: a split photograph hero with a day-timeline foot, mirrored route rows with line drawings on the seam, a fare table on a pale evergreen band, guide portraits with a docked tab and one itinerary request.

- Colours: white, wash #E4EEEA, evergreen #006E54, ink #1B2622, amber #C9962B (the 'now' tick only).
- Fonts: Hanken Grotesk (headings), Public Sans (text), Noto Sans TC / JP subsets for the zh-TW and ja sample content.
- Design notes: brand/design-spec.md, brand/reference.md, brand/reference-tokens.md.
- Scroll effects: assets/sp-scroll.css and sp-scroll.js (sp-reveal, sp-stagger, sp-count, sp-parallax); forms: inc/shippress-forms.php.
