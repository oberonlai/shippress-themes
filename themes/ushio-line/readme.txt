Ushio Line is a harbour ferry theme for a single commuter line in Calder Bay, pier to pier. The front page follows a sailing day across six piers, with fares, boats, crew and notices. Serif headings, a slate and mist palette, and sine-wave links carry the same calm harbour voice through every page.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download ushio-line.zip from the releases page of https://github.com/oberonlai/shippress-themes
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Ushio Line. On activation it creates the home page, eight inner pages (piers, timetable, fares, boats, crew, on board, about, contact), the notices page with six notices and the menu (inc/demo-import.php).

The company, its people, address and prices are fictional.
