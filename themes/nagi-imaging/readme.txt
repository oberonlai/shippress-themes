Nagi Imaging is an accessible, low-key WordPress theme crafted for diagnostic imaging centres and medical clinics. Designed around same-day reporting workflows, it features scattered documentary photography, clear fee schedules, and dual-column narrative layouts. Built with pure Gutenberg block patterns, modern sans typography, and optional WooCommerce support.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes and patterns. Works without WooCommerce.

== Installation ==

1. Download nagi-imaging.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/nagi-imaging.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Nagi Imaging.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, six sample posts with two categories, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The centre, its address, telephone number, people and prices are fictional.
