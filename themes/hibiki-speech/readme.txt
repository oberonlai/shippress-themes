Hibiki Speech is a calm, split-screen WordPress theme designed for speech and language therapy clinics supporting children and adults. Featuring torn-edge photo pairs, hand-drawn crayon accents, and clear fee tables, it offers an unhurried presentation for independent clinical practices. Built for full block editing with refined typography, responsive layouts, and subtle scroll-driven motion.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download hibiki-speech.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hibiki-speech.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hibiki Speech.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with their text and images, three notes with a category and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. It works as a plain site without WooCommerce.

The clinic, its people, address, telephone number and prices are fictional.
