Kashidashi Hire is an austere, documentary-styled WordPress theme built for construction plant hire yards and equipment rental depots. Engineered with a disciplined sans-serif typographic system, bespoke diagonal framing accents and tabbed fleet directories, it presents weekly machine availability with quiet operational clarity. The responsive layout provides structured equipment listings, straightforward hire schedules and seamless date inquiry workflows.

== Description ==
A landing-page theme for a plant hire yard: a slant-cut pine logo tab and wedge around an inset photo hero with a two-cell hire dock, a yard board bar, a peeking strip of machines out this week, a tabbed fleet finder, a horizontal hire-week strip, hairline rate rows and a diagonal request band. Block patterns and sample content are included; the home page is a single long page with one repeated call to action.

== Fonts ==
* Schibsted Grotesk (SIL OFL 1.1): headings, the wordmark and tags.
* Source Sans 3 (SIL OFL 1.1): body text.
Both are bundled as Latin subsets under assets/fonts with their licence files.
