# Hikari Lighting

Hikari Lighting is an editorial block theme crafted for independent lighting showrooms, design studios, and boutique retailers. Inspired by restrained Japanese spatial design, it features a signature lights-on curtain reveal, alternating dark and light perspective layouts, and seamless WooCommerce integration for curated collections. Built with fluid typography and precise mono detailing, every template remains functional and elegant whether commerce features are active or disabled.

## Structure
- `patterns/front-*.php`: the eight home sections (lights-on cover, intro and makers, floor room box, three pieces, rooms rows, specify room box, visit, journal).
- `patterns/header-bar.php`, `footer-main.php`: header and footer parts; `templates/`: block templates.
- `assets/sp-scroll.*`: ShipPress scroll effects (parallax, wipe reveal, marquee).
- Photos: `assets/images/demo/` (AI-generated).

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
