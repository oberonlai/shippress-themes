Hikari Lighting is an editorial block theme crafted for independent lighting showrooms, design studios, and boutique retailers. Inspired by restrained Japanese spatial design, it features a signature lights-on curtain reveal, alternating dark and light perspective layouts, and seamless WooCommerce integration for curated collections. Built with fluid typography and precise mono detailing, every template remains functional and elegant whether commerce features are active or disabled.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download hikari-lighting.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hikari-lighting.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hikari Lighting.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with their text and images, journal entries, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. With WooCommerce active it also adds six sample lamps with four categories (inc/woo-import.php); without WooCommerce the theme works as a plain site.

The showroom, its people, workshops, address, telephone number and prices are fictional.
