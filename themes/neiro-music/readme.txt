Neiro Music is a block theme for a private music school: ink ground, a split hero, and a teaching day set as five sticky rows. It ships with the Ghent school’s facts — founded in 2011, eight teachers, term fees in euro — for a day-schedule site in English and four further languages. Photography is low-key and documentary, with Crimson Pro and Outfit set in theme.json.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes).
