Azuke Finance is a calm, precision-crafted WordPress theme designed for small-supplier invoice factoring and B2B commercial finance. Built with an editorial aesthetic inspired by documentary photojournalism, it features tight modern sans typography, sticky process chapters, and clear fee schedules. Developed for Azuke Finance B.V. in Rotterdam, the theme supports five European languages and responsive, accessible layouts.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes and patterns.

== Installation ==

1. Download azuke-finance.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/azuke-finance.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Azuke Finance.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images and the pages it links to, the anchor menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The company, its address, telephone number, customers and prices are fictional.
