Awa Taproom is a calm, booking-led WordPress block theme designed for small breweries, brewpubs, and independent taprooms. Featuring a framed-window hero, custom horizontal scroll strips, and clean rule-topped cards, it pairs Fraunces serif headings with Nunito Sans body typography. Built around authentic documentary photography and an earthy umber palette, it presents tap lists, table reservations, and brewhouse stories with quiet craftsmanship.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes.

== Installation ==

1. Download awa-taproom.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/awa-taproom.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Awa Taproom.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page, nine inner pages, one Brew Notes article, all their text and images and a menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works without WooCommerce.

The taproom, its people, address, telephone number and prices are fictional.
