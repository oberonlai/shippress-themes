Kazu Data Course — a theme for a solo instructor's online course. A quiet #F8F8F8 ground with thin ink Lora type: an oversized display headline set flush to the left edge of the screen, a framed 3:4 portrait with the instructor's name running vertically over its edge, and white cards with a hard plum-tint offset edge and a pill label on the top border. Alternating photo and text chapters, student work over a pale stone watermark ring, one clear price and a full price table. Lora for headings, Inter for reading. Sample content in English. Works with free Tutor LMS and WooCommerce checkout. WCAG AA colours; calm scroll reveals that respect reduced motion.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes and copy.

== Installation ==

1. Download kazu-data-course.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kazu-data-course.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kazu Data Course.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with their text and images, the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice. Sample content is in English (demo-content.json); the importer uses the `shippress_demo_lang` option, else the site language.

Scroll effects (assets/sp-scroll.css and sp-scroll.js) reveal sections as they enter the screen; they are off with reduced motion and with JavaScript disabled.

The course, people, address and prices are fictional.
