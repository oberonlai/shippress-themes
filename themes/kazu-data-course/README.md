# Kazu Data Course

A calm block theme (type education) for a solo instructor's online course. Home page and starter inner pages (English) in this release; richer inner pages and other languages follow.

## Signature
- T1: oversized thin Lora headline set flush to the left edge, with an italic subline; repeated on the closing section and every inner page head.
- T2: framed 3:4 portrait (8px radius) with the instructor's name running vertically over its right edge.
- T3: white cards with a 1px ink border, a hard 8px plum-tint offset and a pill label riding the top border.
- A pale stone watermark ring behind the second student-work portrait.

Lora and Inter (SIL OFL 1.1, licences in assets/fonts).

## Courses and checkout
Declares WooCommerce support. The Buy buttons use `kazu_buy_url()`: with WooCommerce and a published product they add it to the cart and open checkout; otherwise they link to /pricing/. Filters: `kazu_data_course_product_id`, `kazu_data_course_buy_url`. Designed for free Tutor LMS + WooCommerce.
