Moyooshi Productions is a documentary WordPress theme engineered for live event production companies, staging specialists, and creative venue producers. Featuring hairline cue grids, offset narrative columns, and ledger-based run sheets, it provides a calm and structured presentation for corporate kick-offs, award ceremonies, and product launches. Built for clarity and reliability, the theme includes full-bleed visual sections, transparent pricing schedules, and accessible production profiles.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page opens on a full-bleed documentary photograph of an empty hall being built, with the headline upper left and a bar of hairline-outlined run-of-show cue cells (load-in, rehearsal, doors, strike) docked on its lower edge. Below: the problem in an offset column, a dark teal band with the lit truss, the method as four ledger rows under a giant section word, a mixed-width portrait triptych of works, a ruled row of four figures, a six-row day-of-show run sheet, the crew, the journal and one way to send a brief. Scroll effects (rise, stagger, count-up, parallax) use the small sp-scroll script in assets/ and respect prefers-reduced-motion. The optional newsletter and contact slots work without any plugin and use Contact Form 7, WPForms, MailPoet or Mailchimp for WP when present.

== Installation ==

1. Download moyooshi-productions.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/moyooshi-productions.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Moyooshi Productions. On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): the home page, the journal with sample posts and the menu. Use Tools > Import demo content to run it again.
4. Edit everything in the block editor; the sections are block patterns in the "Moyooshi Productions" category.

The studio, its people, clients, addresses and fees are fictional.

== Forms ==

Contact and brief enquiries: recommended Contact Form 7 fields are name (required), email (required), company, event type (select: Kick-off, Award night, Product launch, Conference, Other), date, guest count and message (required). Without a plugin the page shows an email button that opens your email app. The newsletter box always shows an email field and a submit button; without a mail plugin it opens your email app with the request and says clearly that you are not subscribed yet.
