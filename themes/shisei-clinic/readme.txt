Shisei Clinic is a calm, photographic WordPress theme designed for chiropractic clinics and healthcare practices supporting desk workers. Rooted in an airy split-screen layout with high-key daylight photography and cool slate tones, it presents treatment methods, clear fees, and unhurried practitioner introductions. Built with Figtree and Public Sans typography, the theme emphasizes calm structure and thoughtful patient care.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes and patterns.

== Installation ==

1. Download shisei-clinic.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/shisei-clinic.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Shisei Clinic.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page, the Notes page and one article with all their text and images and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The clinic, its address, telephone number, people and prices are fictional.
