Kamotsu Academy is a clean, focused WordPress block theme designed for commercial driving schools and vocational training facilities. Built around documentary photography, split navigation, and structured timeline layouts, it presents course pathways, yard schedules, and pricing with clarity. Fully compatible with the block editor, the theme provides a calm, functional aesthetic tailored to transport and logistics operations.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download kamotsu-academy.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kamotsu-academy.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kamotsu Academy.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, stories with two categories and four tags, the top menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. WooCommerce is supported but not needed.

Scroll effects: assets/sp-scroll.css and assets/sp-scroll.js (a small script loaded in the head, no libraries). Content stays visible without JavaScript and with reduced motion.

The academy, its people, address, telephone number, figures and prices are fictional. Photographs in assets/images/ are AI-generated and released under CC0.
