# Haru Allergy

A block theme for an allergy and immunology clinic. A full-bleed high-key photo stays pinned to the first screen while a blurred slate veil rises over it and four stanzas of a poem appear one by one; tall portraits sit flush to both viewport edges; a soft line-up band shows the history, the test and the plan; a slate band carries case notes as translucent cards; a rounded paper card holds the patient voices. Figtree for headings, Public Sans for reading.

- Design notes: `brand/design-spec.md`, `brand/reference.md`, `brand/reference-tokens.md`
- Patterns: `patterns/front-*.php` (home), `patterns/foot-main.php`, `patterns/news-slot.php`
- Sample pages: first visit, tests, conditions, immunotherapy, children, fees, about, contact, newsletter and privacy are imported from `demo-content.json`; the menu links to them
- Scroll effects: `assets/sp-scroll.css`, `assets/sp-scroll.js`
- Forms: `inc/shippress-forms.php` (dynamic `shippress/form` block, no required plugin)
