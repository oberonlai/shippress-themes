Hatake Greens is a calm, clean WordPress theme created for weekly farm-to-table vegetable memberships and local delivery cooperatives. Built with full-bleed documentary photography, muted sage accents, and structured typography, it presents harvest routines and subscription plans with clarity and poise. Designed for single-page longform conversion and seamless inner storytelling.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes.

== Installation ==

1. Download hatake-greens.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hatake-greens.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hatake Greens.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The business, its people, address and prices are fictional.
