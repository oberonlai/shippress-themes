A calm serif WordPress theme for a staff-cafeteria contractor: a photo-led hero with a tabbed strip beneath it, abutting workplace photo tiles with overlapping white label tabs over an orange wedge, a service-day slideshow panel, contract rows and a plain rate table.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download mahora-foods.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/mahora-foods.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Mahora Foods.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with their text and images and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The company, its staff, address, telephone number and prices are fictional.
