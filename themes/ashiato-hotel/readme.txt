Ashiato Hotel is a serene WordPress theme crafted for dog-friendly seaside guesthouses, inspired by clean Japanese hospitality aesthetics. It features an inset photo hero window with gentle cross-fading imagery, pale sage paw-print trails, quick-answer FAQ cards, and structured rates tables. Designed with accessible sans typography and dedicated dog-stay block patterns, it presents a calm, practical home for hotels where dogs are welcomed as true guests.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes. Fonts: Lexend (display), Public Sans (text), and Noto Sans TC / Noto Sans JP (zh-TW and ja subsets), all under the SIL Open Font License.

== Installation ==

1. Download ashiato-hotel.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/ashiato-hotel.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Ashiato Hotel.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The hotel, its people, village, address, telephone number and prices are fictional.

== Forms ==

The register letter section on the home page and the Newsletter page use the shared form slot (inc/shippress-forms.php). Without a form plugin they show a real email field and a submit button that opens the visitor's email app with the address; the notice says plainly that the visitor is not subscribed until that message is sent. MailPoet or Mailchimp for WP are used when active. The Contact and Book pages show the first Contact Form 7 or WPForms form when one exists, and a mailto button otherwise.
