== Description ==

Nodoka Counselling is a calm, split-screen WordPress theme designed for psychotherapy and counselling practices. Built with an unhurried editorial aesthetic, it features quiet low-key photography, clear ruled section openers, and refined typography. The theme provides complete, accessible layouts for practice introductions, practitioner profiles, transparent fee schedules, and confidential booking.

Fonts: Instrument Sans, Public Sans, Noto Sans TC and Noto Sans JP (SIL Open Font License 1.1), bundled. Photographs were generated for this theme. The scroll effects (sp-scroll) respect the visitor's reduced-motion setting and stay visible without JavaScript.
