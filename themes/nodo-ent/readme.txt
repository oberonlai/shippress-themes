Nodo Clinic is a quiet documentary theme for an adult ear, nose and throat practice, seen by appointment in Ghent. Eleven inner pages (about, complaints, four complaint pages, first visit, clinicians, fees, patient stories, contact) and a notes index follow the same paper-strip heads. The front page follows one visit from the complaint to the people, the stories and the door. Copy, fees and hours are fixed to the practice, and the photographs are original.

== Description ==

A WordPress block theme from ShipPress. See README.md for the design notes, templates and patterns, and brand.md for the fictional clinic the sample content is written for.

== Installation ==

1. Download nodo-ent.zip from the theme's release.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Nodo Clinic.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php, driven by demo-content.json): it creates its pages with all their text and images, sample posts with categories and tags, the menu, and sets the front page and posts page. It never changes or deletes existing content, and running it again only adds what is missing. If the automatic setup did not run, use the "Import demo content" button shown in wp-admin, or run: wp shippress demo-import

Booking is by phone or email; no plugin is needed.
