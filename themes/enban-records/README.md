# Enban Records

A WooCommerce store theme for an independent record shop where people listen before they buy. One room, one turntable, one listening desk.

- **Signature techniques:** (1) a docked black 40 px keyword bar "On the desk this week"; (2) five-up square sleeve cards with a format disc, a bold price with a small tax suffix and a full-width outline status box; (3) centred section heads with a grey caps sub-label between full-width hairlines and a 330 x 55 outline box button with a chevron.
- **Home:** header overlay + docked bar, hero (headline beside an inset photo card with a peeking next photo, square tabs and dots, timeline band), who comes to the desk (ruled rows), how a listening works (horizontal line), this week's crate, parallax counter band, the counter story, ranked stories, visit, the Friday letter.
- **Type:** Newsreader (headings), Literata (text); CJK headings Noto Serif TC / JP.
- **Colour:** ground `#FBFAFB`, ink `#0E0C0F`, grape grey `#65586A`, lilac-grey band `#ECE8EE`, one muted red `#B4473A`.
- **Motion:** sp-scroll (reveal, stagger, parallax), a click-only photo strip, a one-off timeline draw; all respect reduced motion.
- **Forms:** `shippress/form` dynamic block (contact and newsletter) with plugin detection and a mailto fallback.
- Design notes: `brand/design-spec.md`, brand brief: `brand.md`.
