# Yunagi Jazz

Yunagi Jazz — a block theme for an open-air jazz festival on one harbour lawn for one summer weekend. Three equal rounded low-key photographs sit on an ink mat with the headline over their bottom edge; a row of set cards drifts left and pins behind white rounded sheets; a plum quarter-disc date badge stays fixed in the corner. It continues with the weekend, Saturday and Sunday as hour rows, what a ticket includes, a parallax photograph of the lawn at dusk, the crew, one dark sheet with the single way to buy tickets, and the journal. Bodoni Moda for headings, Karla for reading. Works without WooCommerce. WCAG AA colours; scroll effects respect reduced motion.

## Structure
- `patterns/front-*.php`: the home sections (hero, weekend, saturday, sunday, ticket, lawn, crew, buy, journal).
- `patterns/header-main.php`, `footer-main.php`, `tpl-*.php`: header, footer (newsletter slot and the date badge), journal, archives, single post and 404.
- `inc/i18n/<lang>.php`: theme strings; `demo-content*.json`: sample content.
- Photos: `assets/images/` (AI-generated low-key documentary photographs). See `readme.txt`.

Design notes: `brand.md`, `brand/`.
