Shirabe Research is a quiet, editorial WordPress theme designed for qualitative research practices, advisory consultancies, and independent studios. Featuring a framed-window hero, serif typography, and structured ledger layouts, it presents case studies, fieldwork methodologies, and transparent fee tables with calm clarity. Built with block editor support, elegant motion tokens, and clean monochrome palettes.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download shirabe-research.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/shirabe-research.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Shirabe Research.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice. Sample content is in English (demo-content.json).

The practice, its people, address, telephone number and prices are fictional.
