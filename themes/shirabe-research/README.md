# Shirabe Research

Shirabe Research is a quiet, editorial WordPress theme designed for qualitative research practices, advisory consultancies, and independent studios. Featuring a framed-window hero, serif typography, and structured ledger layouts, it presents case studies, fieldwork methodologies, and transparent fee tables with calm clarity. Built with block editor support, elegant motion tokens, and clean monochrome palettes.

## Structure
- `patterns/front-*.php`: the home sections (headline row, framed window, brief, method, numbers, studies, people, fees, contact).
- `templates/`: block templates; `parts/`: header and footer.
- `assets/sp-scroll.*`: scroll effects (reveal, wipe, count, parallax, marquee).
- `demo-content.json`: sample content (English).

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
