Eiyo Clinic is a calm, typography-first WordPress theme designed for adult nutrition and dietetics practices. Inspired by editorial Japanese web design, it pairs warm high-key documentary photography with structured consultation schedules and transparent fee lists. Built with clean block patterns and subtle scroll motion, it presents everyday nutrition care with quiet clarity.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download eiyo-clinic.zip from the ShipPress themes releases.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme and install the zip.
3. Activate Eiyo Clinic. On activation it creates the home page, the Journal page and the menu (inc/demo-import.php). It never changes what you wrote.

The clinic, people, address, telephone number and prices are fictional.
