Fumoto Hostel is a calm, daylight-filled WordPress theme designed for urban hostels, guesthouses, and independent lodgings. Built around warm serif typography, organic pebble-framed imagery, and alternating white and pale sage palettes, it presents rooms and communal house routines with unhurried clarity. It provides dedicated block patterns for dormitories, private rooms, and neighbourhood guides to welcome travelers with thoughtful simplicity.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes and patterns.

== Installation ==

1. Download fumoto-hostel.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/fumoto-hostel.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Fumoto Hostel.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The hostel, its people, address and prices are fictional.
