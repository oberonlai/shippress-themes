== Description ==

Kosei Architects is a block theme for an architecture studio working on workplaces, housing and renovation. It presents the Brussels practice founded in 2008: eight people, a case wall of finished buildings, and fees stated before design begins. The front page leads with recent work, then the services, the four project stages and a first meeting by appointment. It declares WooCommerce support and works fully without WooCommerce installed. The home page opens on a framed panel grid with a timber-model photograph and diagonal bands beside a numbered index list. A wall of finished buildings, each read as question, work and result, follows, then a ruled services table, a darkened parallax interlude, the process as an index list, notch and arch photographs of the studio, the fee list and the journal. Source Serif 4 for headings, Source Sans 3 for reading.
