## Notes

- Theme type is `business`: the shop shows mouldings and a price schedule but sells by appointment, so there is no WooCommerce checkout.
- Home page only is fully built in this release stage; the inner pages are placeholders and the zh-TW, ja, fr and de languages are not built yet.
