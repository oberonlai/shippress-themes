Gaku Frames is a calm, documentary-style WordPress theme built for bespoke picture framers and craft workshops. Featuring walnut-framed window displays, hand-cut mitre details, and asymmetric masonry layouts, it presents custom framing services with quiet precision. Designed for clear typography, transparent pricing schedules, and effortless appointment scheduling.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page opens on a walnut picture frame whose four corners show real 45-degree mitre joints and which holds three butted low-key photographs, with one centred label and a dark "on the bench today" card docked over the frame's corner. Behind the page run mitre hairlines and a vertical rule with a small caption; section headlines are split into a giant word and an indented "/" second line. Below: an asymmetric masonry of woods in wood-coloured frames, a framed parallax band, four alternating mount rows, a full-width price table, delivery and hanging, the journal and a closing booking card. Scroll effects (headline rise, mosaic wipes, parallax) use the small sp-scroll script in assets/ and respect prefers-reduced-motion. The optional newsletter and contact slots work without any plugin and use Contact Form 7, WPForms, MailPoet or Mailchimp for WP when present.

== Installation ==

1. Upload the theme and activate it under Appearance > Themes.
2. On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page, the journal page with sample posts and the menu, and sets the front page and posts page. Use Tools > Import demo content to run it again.
3. Edit everything in the block editor; the sections are block patterns in the "Gaku Frames" category.

The shop, its people, address, telephone number and prices are fictional.
