Ayumi Podiatry is a calm, accessible WordPress block theme designed for podiatry clinics, foot-care practices, and healthcare professionals supporting people who work on their feet. Built with quiet olive tones, clear sans typography, and an unhurried editorial structure, it presents clinical care, gait assessments, and transparent fee schedules with clarity. Fully compatible with the WordPress block editor and optional WooCommerce support, it offers dependable responsive layouts tailored for professional clinic websites.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download ayumi-podiatry.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/ayumi-podiatry.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Ayumi Podiatry.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice. Works without WooCommerce.

The clinic, its people, address, telephone number and prices are fictional.
