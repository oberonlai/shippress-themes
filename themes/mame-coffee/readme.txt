Mame Coffee is an editorial WordPress theme designed for independent specialty coffee roasteries and tasting bars. Structured around documentary film photography, refined serif type, and quiet grids, it presents daily roasting schedules, seasonal farm lots, and bar service without clutter. It works seamlessly as a standalone informational website or paired with WooCommerce.

== Description ==

A WordPress block theme from ShipPress. See README.md for the design notes, templates and patterns, and brand.md for the fictional roastery the sample content is written for.

Scroll effects (assets/sp-scroll.css, assets/sp-scroll.js): a slow parallax on the hero, origin and band photographs, a gentle rise-in for the card columns and a wipe on the pour photograph. They are off with prefers-reduced-motion, without JavaScript and inside the editor.

== Installation ==

1. Download mame-coffee.zip from the theme's release.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Mame Coffee.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php, driven by demo-content.json): it creates its pages with all their text and images, sample posts, the menu, and sets the front page and posts page. It never changes or deletes existing content, and running it again only adds what is missing. If the automatic setup did not run, use the "Import demo content" button shown in wp-admin, or run: wp shippress demo-import
