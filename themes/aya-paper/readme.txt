Aya Paper is a block theme for a stationery shop in Ghent, with WooCommerce shop templates and eight sample products. The same pages still read clearly when WooCommerce is not active, using the paper list as plain text. The home page is a quiet catalogue: a hairline frame of three photographs, six ruled paper rows with prices in EUR, and a text list of what each weight suits.

== Description ==

Inner pages: Shop (static spec rows, or the WooCommerce shop), Papers, Weights, The Counter, Envelopes & Notebooks, Prices & Delivery, About, Journal, Newsletter and Contact. Eight sample products are added by inc/woo-import.php only while WooCommerce is active; running it again adds nothing twice.

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

Fonts: Figtree (headings, navigation, figures; SIL OFL 1.1) and Public Sans (body text; SIL OFL 1.1), both bundled as Latin variable subsets in assets/fonts/. Noto Sans TC and Noto Sans JP (SIL OFL 1.1) are bundled as subsets of the Traditional Chinese and Japanese sample text for the headings. Chip, meta and spec lines use the system monospace stack.

== Installation ==

1. Download aya-paper.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/aya-paper.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Aya Paper.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, the journal entries with their categories and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. Without WooCommerce the theme works as a plain site.

Scroll effects: assets/sp-scroll.css and assets/sp-scroll.js (reveal, stagger and parallax). They respect prefers-reduced-motion, show everything without JavaScript and stay still inside the editor.

The shop, its address, people, prices and photographs are fictional. Photographs were generated with AI and are released under GPL-2.0-or-later.
