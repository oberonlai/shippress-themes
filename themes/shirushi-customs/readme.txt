Shirushi Customs is a quiet WordPress block theme for a small customs broker that clears imported goods for small manufacturers. A dark documentary stage with a statement that rides up and a five-tick timeline line opens on cool paper, followed by dossier cards where photograph and text are one unit, a blurred quay band with a sharp window and an outline map, a ruled document list, a fee table and a notice panel. Onest for headings and Source Sans 3 for reading.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download shirushi-customs.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/shirushi-customs.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Shirushi Customs.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, six notes with three categories and three tags and the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The desk, its clients, address, telephone number and prices are fictional.
