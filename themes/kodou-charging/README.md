# Kodou Charging

Single-column landing theme for a workplace EV charging installer: split photo-left hero with an outlined booking bar, filled-cell site tabs (no JavaScript), a centred statement with two line-pictogram columns, assessment tiles, a price table, story rows and a flat FAQ. Home is one long conversion page with an anchor menu and one repeated request.

See `brand.md` and `brand/design-spec.md`.
