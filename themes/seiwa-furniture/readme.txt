Seiwa Furniture is a block theme for an Eindhoven office-furniture manufacturer that builds task and meeting seating, desking systems, acoustic panels, and meeting tables to architects’ drawings. The home page pairs a factory photograph with a 2025 delivery ledger, a 2026 price list in euros, and a sample-kit request. Showroom hours, the Thursday factory tour, a 6-week lead time, and the frame warranty are the same facts on every page.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download seiwa-furniture.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/seiwa-furniture.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Seiwa Furniture.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): pages, three notes, the menu and the front page. It never changes or deletes anything you wrote. The company, people, projects and prices are fictional.
