Budou Academy is a serene, typography-driven WordPress theme created for sommelier schools and hospitality academies. Built with full-site editing support, it features a calm documentary aesthetic, practical course schedule layouts, and structured tuition fee tables tailored for working service professionals. The theme pairs refined editorial typography with responsive, accessible block patterns across modern devices.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes, patterns and fixed numbers.

== Installation ==

1. Download budou-academy.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/budou-academy.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Budou Academy.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with their text and images, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. Works without WooCommerce.

The school, its people, address, telephone number and prices are fictional.
