== Description ==

Soroe Clinic is a calm, modern WordPress theme designed for orthodontic practices caring for teenagers and adults. Built with clean sans-serif typography, subtle line paths, and modular framed cells, it presents treatment courses, transparent fees, and clinical workflows with clarity. Fully compatible with the block editor, it offers accessible layouts and structured scheduling sections for contemporary clinics.

The home page opens on a pale framed cell with one tall rounded photograph, the headline beside it and a single hand-drawn thread line, then notice rows, the worries people arrive with, a slate band of three photographs with pale numerals hung across their corners, a parallax review-visit band, one example course in figures, staggered patient notes, a full-width fee table, a team list, first-visit steps with opening hours, and a Letters sign-up. Contact and newsletter forms use the optional ShipPress form slot and need no plugin.

== Fonts ==
