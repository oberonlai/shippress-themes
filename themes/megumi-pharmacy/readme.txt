Megumi Pharmacy is a block theme for an independent community pharmacy on Queen Street East in Toronto, opened in 2006 by pharmacist Megumi Ward. The front page is a calm, photographic long read of the counter, the six people, and the neighbourhood shop. WooCommerce can run the counter shelf and checkout, and the theme still renders when WooCommerce is not installed.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes and patterns.

== Installation ==

1. Download megumi-pharmacy.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/megumi-pharmacy.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Megumi Pharmacy.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, three notices in a Notices category and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The pharmacy, its people, address, telephone number and prices are fictional.
