# Megumi Pharmacy

A calm block theme (type store, WooCommerce-compatible) for an independent community pharmacy. Home page (English) in this release; inner pages and the other languages follow.

## Signature
- One full-bleed photograph is the stage for the hero and the introduction; the white page slides up over it (sp-parallax).
- Three 0.77 portrait link cards with the label inside the photograph, bottom left.
- Numbered rows 01-05 with hairlines on a pale inset panel beside a 3:4 photograph whose neighbour peeks at the window edge.

## Patterns
- `front-stage`
- `front-ways`
- `front-people`
- `front-story`
- `front-process`
- `front-notices`
- `front-shelf`
