Tsubasa College is an editorial aircraft maintenance college WordPress theme designed for licence-track academies and aviation technical colleges. Built with Fraunces and Source Sans 3 typography, it features a focus-pull hangar hero, a horizontal 18-month curriculum ruler, an isometric module overview, and clean fee ledgers. The theme emphasizes clarity, technical precision, and practical workshop learning in a calm, professional design.

== Description ==
A block theme for an aircraft maintenance training college. The home page opens on a full-bleed hangar photograph whose sharp centre window is flanked by blurred, stretched bands of the same frame, with a slate cohort strip and a white notice card from the left edge. Below: an intro with three narrative paragraphs and chevron module links, an isometric field of eight module tiles on one rotated plane, a horizontal 18-month ruler, a certification ledger, a parallax hangar band with the daily routine, instructor cards, a fee table with intake dates, the journal and a newsletter band, closed by a grey five-column sitemap footer.

= Fonts =
* Fraunces (headings, wordmark, numbers), SIL Open Font License 1.1.
* Source Sans 3 (body text, menu, labels), SIL Open Font License 1.1.
* Noto Serif TC and Noto Serif JP (headings on the Traditional Chinese and Japanese sample content, subset), SIL Open Font License 1.1.

= Images =
The sample photographs were generated for this theme. They contain no text, logos or real people.

= Forms =
The newsletter and contact forms use a dynamic block that shows a Contact Form 7, WPForms, MailPoet or Mailchimp for WP form when one is active. Without a plugin the newsletter form still has an email field and a submit button that opens your email app with the address filled in; nothing is stored by the theme.
