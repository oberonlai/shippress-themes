# Kyukyu College

Editorial block theme for a paramedic training college. Navy ink on a cool grey ground, a hairline page frame with a centre split, a giant section word with a red subtitle, a three-line name lockup beside a framed photograph under crossed translucent polygons, sticky term chapters with red numerals, a ruled ride-along week and a six-row price list. Stage 1 ships the English home page; inner pages and four more languages follow.

See brand.md and brand/design-spec.md.
