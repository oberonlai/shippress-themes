Kyukyu College is an editorial magazine-style WordPress theme designed for paramedic colleges, emergency medical schools, and clinical training institutions. Built around a refined tetsu-kon navy palette with crisp hairline frames and dynamic serif typography, it showcases pre-hospital education through structured course timelines, scenario simulations, and transparent fee schedules. The theme features dedicated block patterns for clinical diploma programmes, frontline ride-along placement tracking, and open campus visits.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download kyukyu-college.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kyukyu-college.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kyukyu College.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, six stories with two categories and five tags, the top menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. WooCommerce is supported but not needed.

Scroll effects: assets/sp-scroll.css and assets/sp-scroll.js (a small script loaded in the head, no libraries). Content stays visible without JavaScript and with reduced motion.

The college, its people, address, telephone number, figures and prices are fictional.
