Oto Audio is a WordPress block theme for a hi-fi shop and listening room in Rotterdam, founded in 2012. It presents eight house products — headphones, amplifiers, a DAC and speakers — with comparison, services, journal and visit pages, and prices in euro. Checkout is built for WooCommerce, and the theme still renders when WooCommerce is not active.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the brand brief and brand/design-spec.md for the design notes.

== Installation ==

1. Download oto-audio.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/oto-audio.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Oto Audio.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The shop, its products, address, telephone number and prices are fictional.
