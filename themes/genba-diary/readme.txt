Genba Diary is a single-column longform landing WordPress theme for construction site-diary apps and crew rollouts. Built around a diagonal-split hero with a slanted photo triptych, a clean anchor menu and a single repeated request button, it presents a six-section daily log, a seven-day pilot, crew use cases and transparent per-site pricing. Five-language compatible, with high-key documentary photography and clean sans typography.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download genba-diary.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/genba-diary.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Genba Diary.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, five field notes with two categories and six tags, the top menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. WooCommerce is supported but not needed.

Scroll effects: assets/sp-scroll.css and assets/sp-scroll.js (a small script loaded in the head, no libraries). Content stays visible without JavaScript and with reduced motion.

Inner pages: About, Crews, A diary day, Rollout, Plans, Waitlist, Request, Privacy, Terms and Thanks, plus the Field notes list and single stories. The request form sends to the Thanks page and the waitlist form opens an email to the rollout address; both are plain HTML forms you can point at your own form service.

The company, its people, address, telephone number, customers, figures and prices are fictional.
