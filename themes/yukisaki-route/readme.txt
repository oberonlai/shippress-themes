Yukisaki Route is a quiet, documentary-style WordPress theme designed specifically for regional courier dispatch desks and small delivery fleets. Built for clarity and speed, it provides white dossier cards, frosted statement panels, and road-tested round sheets that bring calm order to morning deliveries. Ideal for regional logistics businesses operating between 3 and 25 vans that value dependable workflows and paper-first dispatch.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download yukisaki-route.zip from the releases page of https://github.com/oberonlai/shippress-themes
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Yukisaki Route. On activation it creates the home page, the inner pages, the field notes page with one article and the menu (inc/demo-import.php).

The company, its people, address and prices are fictional.
