Misora Links is an understated, serif-led WordPress theme designed for traditional members' golf clubs and hospitality retreats. Rooted in coastal atmosphere, it features ticket-notch frames, a horizontal morning sheet rail, and balanced editorial typography. Built with modern block patterns, the theme delivers calm, dependable performance across all devices. Cormorant Garamond for headings, EB Garamond for reading.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download misora-links.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/misora-links.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Misora Links.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, six journal entries with three categories and four tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

Fonts: Cormorant Garamond and EB Garamond (SIL Open Font License 1.1), bundled in assets/fonts, plus Noto Serif TC and Noto Serif JP subsets for the Chinese and Japanese headings.

The club, its address, people, prices and photographs are fictional; the photographs are AI-generated.
