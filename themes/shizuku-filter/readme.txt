Shizuku Filter is a calm, responsive WordPress landing theme designed for small-batch maker crowdfunding campaigns. Built with full-pill capsule layouts, an 80px vertical rail, and refined sans-serif typography, it showcases products through high-key documentary photography and clear, grounded storytelling. Developed for the Shizuku Countertop Filter workshop in Rotterdam, Netherlands.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download shizuku-filter.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/shizuku-filter.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Shizuku Filter.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page and eleven inner pages (rewards, filter, schedule, story, FAQ, updates, waitlist, contact, privacy, terms, thanks) with their text and images, one sample article, the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The company, its people, rewards, prices and campaign figures are fictional.
