Hitomi Vision is an independent optometry clinic theme for a practice that sees office workers and school-age children. It presents a sixty-minute exam, straightforward fees in US dollars, and individual case accounts without promising a result. The design is a calm, high-key, single-column narrative with room for the clinic's own photographs.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download hitomi-vision.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hitomi-vision.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hitomi Vision.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its home page with all its text and images, the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice. WooCommerce support is declared but not needed.

The clinic, its people, address, telephone number and prices are fictional.
