Kogarashi Inn is a single-column longform WordPress block theme designed for country inns, small lodges, and quiet retreats. Crafted with a calm day-schedule layout and refined serif typography, it presents rooms, communal dining, and fell walks with quiet documentary clarity. Built for block editing across five languages, the theme features bespoke time-stamped logs, mist gradients, and subtle film-grain imagery.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes and the fixed facts of the sample inn.

== Installation ==

1. Download kogarashi-inn.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kogarashi-inn.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kogarashi Inn.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, journal entries with categories and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. Works without WooCommerce.

The inn, its people, address, telephone number and prices are fictional.
