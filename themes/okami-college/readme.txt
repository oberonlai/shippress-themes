Okami College is a classic editorial WordPress theme tailored for vocational hotel management schools with integrated teaching hotels. Combining an outcomes-first structure with refined Fraunces and Source Serif typography, it presents course pacing, operational desks, and graduate placements with calm clarity. Designed for real hospitality education, it offers a complete institutional web presence without unnecessary complexity.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). Fonts: Fraunces for headings and Source Serif 4 for reading (both OFL-1.1, bundled in assets/fonts).

== Installation ==

1. Download okami-college.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/okami-college.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Okami College.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, sample posts with categories and tags and the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works without WooCommerce.

The college, its people, address, telephone number and fees are fictional.
