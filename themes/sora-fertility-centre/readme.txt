A calm, answers-first block theme for a fertility clinic.

== Description ==

Sora Fertility Centre opens on a full-bleed, film-grain photograph with an information bar, then answers first: an expandable FAQ sits on a huge lighter arch field. A director's letter runs in two offset columns beside a photograph on a tilted paper sheet, and three offset portrait bands introduce the paths in. Spectral for headings, Open Sans for reading. Works without WooCommerce.

= Fonts =
Spectral and Open Sans, both SIL Open Font License 1.1, bundled in assets/fonts.

= Images =
All photographs are generated for this theme and are licensed GPL-2.0-or-later with it.

= Scripts =
assets/sp-scroll.js (about 2 KB) adds quiet scroll effects. It respects prefers-reduced-motion and the content is fully visible without JavaScript.
