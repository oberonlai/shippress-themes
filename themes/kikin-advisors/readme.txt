Kikin Advisors is an independent workplace pension consultation theme for UK employers and fee-only advisers. Built around a calm sixty-minute briefing methodology, it combines hand-drawn line illustrations with clear fee schedules and structured guidance. The theme provides complete editorial clarity for organisations selecting or re-tendering workplace pension schemes.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download kikin-advisors.zip from the releases page of https://github.com/oberonlai/shippress-themes
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kikin Advisors. On activation it creates the home page, the inner pages, one sample note and the menu (inc/demo-import.php).

The practice, its people, address, telephone number and prices are fictional.
