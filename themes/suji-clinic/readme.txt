Suji Clinic is a block theme for Suji Sports Medicine Clinic, a 2014 practice on Millrace Road in Easthaven for club athletes and amateur runners. The home page moves from the problem of rest, through the injuries treated, to a three-stage method and the checks that mark a return. Copy and photography stay documentary and specific, with fees, hours and thresholds stated as clinic facts.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md and brand/design-spec.md for the design notes.

== Installation ==

1. Download suji-clinic.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/suji-clinic.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Suji Clinic.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with their text and images and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The sample content is in demo-content.json (English); WooCommerce is supported but not needed.

The clinic, its people, address, telephone number and prices are fictional.
