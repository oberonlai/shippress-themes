# Hatoba College

Hatoba College is a serif editorial WordPress theme for a maritime training college founded in 1987 at Pier 3, Port Ellery. The front page opens with a framed harbour photograph, then follows a twelve-week course from shore school to a berth confirmed in writing.

## Structure
- `patterns/front-hero.php`: framed 2.4:1 window (three cross-fading photographs, docked navy caption bar, white pager notch, contact-sheet strip, week-tick line, headline row).
- `patterns/front-*.php`: college, course (five stage bars), berth confirmed, quay band (parallax), a day on the quay (photo trio), programmes ledger, cadet stories, journal, newsletter band.
- `assets/hero.js`: hero slideshow controls only. `assets/sp-scroll.css`, `assets/sp-scroll.js`: scroll reveal, count and parallax (unchanged shared files).
- `assets/shippress-forms.css`, `inc/shippress-forms.php`: optional contact and newsletter forms (mailto fallback without plugins).
- `inc/i18n/<lang>.php`: theme strings; `demo-content.json`: sample content.

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
