# Wariate Shifts

Wariate Shifts — a landing-page theme for shop rota software. White ground, grape-mouse folder tabs with numbered steps, four shop photographs edge to edge under one shallow arch, slash-flanked captions over one pill call to action, reason cards with hanging numerals, a sixty-minute time bar and a drifting row of shop kinds. Inter Tight and Albert Sans. Demo: Wariate Shifts is rota software for independent shops with 1 to 6 locations and 5 to 60 staff. Lay out the week, collect availability, swap shifts, cover a sick day, and export hours for payroll. Book a free 60-minute demo; the first month on any plan is free, and nothing is charged automatically.

## Structure
- `patterns/front-*.php`: the eleven home sections (hero with the arched strip, the week, four reasons, the folder-tab demo panel, which shops, the parallax morning band, the sixty-minute time bar, prices, stories, questions and the booking band).
- Inner pages (demo content, editable in the page editor): Features (five folder-tab panels), Prices, Stories, About, Early access, Book a demo, Privacy, Terms and Thanks, plus the News index and three posts. Each head carries the arched photo band; the menu links to the real pages.
- `templates/`: front page, page, single, archive, tag, search, 404. `parts/`: header (utility strip, sticky bar, anchor menu, one CTA) and footer (with the floating CTA bar).
- Photos: `assets/images/demo/` (AI-generated, GPL-2.0-or-later / CC0). See `readme.txt` for the list.
- Scroll effects: `assets/sp-scroll.css`, `assets/sp-scroll.js` (marquee, parallax, reveal).

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`, `brand/reference-tokens.md`.
