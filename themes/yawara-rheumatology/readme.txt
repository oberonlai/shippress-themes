Yawara Rheumatology is a calm, daylight-inspired WordPress theme designed for rheumatology practices and specialized medical clinics. Built with a signature half-and-half hero screen, drifting photographic strip, seam tab cards, and a narrative-problem-method-proof structure, it presents clinical care with quiet clarity. The theme combines Figtree and Public Sans typography with accessible, content-focused block patterns and refined responsive layouts.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). On activation it sets itself up as a ready-to-use website (inc/demo-import.php): pages with text and images, three journal entries with categories and tags, the menu, and the front page and posts page. It never changes or deletes anything you wrote.

The clinic, its people, address, telephone number and fees are fictional.

== Installation ==

1. Download yawara-rheumatology.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/yawara-rheumatology.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Yawara Rheumatology.
