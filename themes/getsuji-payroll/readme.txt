Getsuji Payroll is a calm, photographic WordPress landing theme designed for independent payroll bureaus and accountancy practices. Built for small business services, it features framed full-bleed imagery, hairline editorial typography, and structured fee tables that present monthly closing cycles with clarity. The clean aesthetic pairs Figtree and Manrope typography with refined offset grid accents to establish immediate professional trust.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download getsuji-payroll.zip from the ShipPress themes releases.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme and install the zip.
3. Activate Getsuji Payroll. On activation it creates the home page, the Notes page with three sample notes and the menu (inc/demo-import.php). It never changes what you wrote.

The bureau, people, address, telephone number and prices are fictional.
