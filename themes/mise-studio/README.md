# Mise Studio

Mise Studio is a commercial kitchen design theme crafted for planning studios, hospitality consultants, and technical design practices. Built around a calm, documentary aesthetic, it features structured room sheets, transparent fee schedules, and full-scale layout test workflows. Designed with responsive sans typography and clear booking paths to turn kitchen visits into completed commissions.

Part of [ShipPress themes](https://github.com/oberonlai/shippress-themes). Design brief: `brand.md`; design notes: `brand/`.

## Features

- Framed-window hero: a 72/28 documentary photograph with a thin white stepped outline drawn around the cooking line, and a flat side panel.
- Hollow-ring headings on white 948px sheets, dotted links and dated rows.
- Grey-bar accordions with three-photo sheets, and a parallax full-bleed service band.
- Main menu links to the real inner pages (Studio, Rooms, Site test, Fees, Kitchens, Journal); one booking pill in the header.
- Newsletter and contact forms use the shared form slot (MailPoet, Mailchimp for WP, Contact Form 7 or WPForms when active; a mailto fallback otherwise).
- Fonts: Libre Franklin (display) and Public Sans (body), loaded through theme.json; the block editor shows the same fonts as the front end.
- Languages: en, zh-TW, ja, fr, de (sample content and interface strings).
