# Yukiki Shoes

Store theme for an independent shoe shop: a 4 x 3 contact sheet of abutting photo tiles beside the headline, a five-tick fitting timeline under the split, numbered gateway tabs, a horizontal fitting timeline, a shelf of lasts, a parallax shelf band, fitter notes with avatars, a price list, hours and a letter.

See `brand.md` and `brand/design-spec.md`.

- Fonts: Inter Tight and Public Sans (OFL-1.1), loaded through `theme.json` fontFace.
- Forms: the letter section uses the shared dynamic form block (`inc/shippress-forms.php`).
- Scroll effects: `assets/sp-scroll.css` and `assets/sp-scroll.js` (stagger, reveal up, parallax, count); the gateway tabs use `assets/ys-tabs.js`.
