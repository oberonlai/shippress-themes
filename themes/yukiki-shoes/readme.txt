Yukiki Shoes is a store theme for an independent shoe shop founded in 2011 at 14 Lantern Row, Halden. Visitors book a forty-five-minute fitting, read a plain price list, and can use the site fully without a shop plugin. The voice is calm and specific: lasts, minutes, and the people who fit them.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns. Fonts: Inter Tight and Public Sans (SIL Open Font License 1.1); Noto Sans TC and Noto Sans JP are the Chinese and Japanese fallbacks added with the translations.

== Installation ==

1. Download yukiki-shoes.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/yukiki-shoes.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Yukiki Shoes.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, sample posts with category and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

Optional forms: the letter section uses a dynamic form block (inc/shippress-forms.php). Without a form plugin it shows an email field with a submit button that opens the visitor's email app with the request ready to send (the theme sends nothing itself). With MailPoet (explicit form ID) or Mailchimp for WP, that plugin's form is shown instead.

Scroll effects: assets/sp-scroll.css and assets/sp-scroll.js (reveal, stagger, parallax, count). They respect prefers-reduced-motion and show everything without JavaScript. The gateway tabs use assets/ys-tabs.js and show all panels without JavaScript.

WooCommerce: support is declared; the theme works fully without it.
