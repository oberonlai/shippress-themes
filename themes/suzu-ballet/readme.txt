Suzu Ballet is a calm, classical WordPress block theme designed for dance schools, academies, and movement studios. Built around signature arched framing, a day-schedule layout, and subtle palette tones, it presents class timetables, fee structures, and daylight photography with understated elegance. Compatible with full-site editing and responsive across all viewports, the theme provides clear educational storytelling with no unnecessary decoration.

== Description ==

A WordPress block theme from ShipPress. See README.md for the design notes, templates and patterns, and brand.md for the fictional ballet school the sample content is written for.

Scroll effects (assets/sp-scroll.css, assets/sp-scroll.js): a slow parallax on the hero arch photograph and the greige band, a gentle rise-in for text columns and a mask reveal on the portraits. They are off with prefers-reduced-motion, without JavaScript and inside the editor.

== Installation ==

1. Download suzu-ballet.zip from the theme's release.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Suzu Ballet.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php, driven by demo-content.json): it creates its pages with all their text and images, a sample post, the menu, and sets the front page and posts page. It never changes or deletes existing content, and running it again only adds what is missing. If the automatic setup did not run, use the "Import demo content" button shown in wp-admin, or run: wp shippress demo-import
