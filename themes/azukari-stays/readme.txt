Azukari Stays is a calm, documentary-style WordPress theme designed for holiday-let management companies and property caretakers who represent absentee owners. Built with clean typography, a five-stage service flow, and an interactive floor plan, it emphasizes operational transparency from initial onboarding through monthly owner payouts. It provides a structured, responsive layout with dedicated sections for fee schedules, home portfolios, and owner consultations. Outfit for headings, Inter Tight for reading.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the brief.

== Installation ==

1. Download azukari-stays.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/azukari-stays.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Azukari Stays.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The booking and waiting-list sections use an optional form slot (inc/shippress-forms.php). With Contact Form 7 or WPForms active the contact form is shown; with MailPoet or Mailchimp for WP the waiting-list form is shown. Without a plugin the slot shows a mail button and an email field that opens the visitor's email app, with a clear notice that nothing has been sent.

Fonts: Outfit, Inter Tight, Noto Sans TC and Noto Sans JP (SIL Open Font License 1.1), bundled in assets/fonts.

The company, its people, homes, prices and figures are fictional.
