Fukubi Clinic is a clean, accessible block theme tailored for outpatient gastroenterology, digestive health, and medical specialist practices. Built around calm slate tones and precise typography, it features dot-matrix timetable cards, multi-circle hero compositions, and structured symptom indexes. Every layout prioritises patient clarity, transparent fee disclosures, and unhurried clinical storytelling.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). Fonts: Figtree for headings and Public Sans for reading (both OFL-1.1, bundled in assets/fonts).

== Installation ==

1. Download fukubi-clinic.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/fukubi-clinic.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Fukubi Clinic.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, sample notes with categories and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works without WooCommerce.

The clinic, its people, address, telephone number and prices are fictional.
