Fuchi Glazing is a WordPress theme designed for commercial glazing contractors, shopfitters, and architectural glass specialists. Built around an asymmetric diagonal-split hero, dual-tier navigation, and clean ledger sequences, it presents opening surveys, fixed pricing, and replacement workflows with calm clarity. All templates use native block patterns and responsive typography in Onest and DM Sans.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns. Fonts: Onest, DM Sans, Noto Sans TC and Noto Sans JP (SIL Open Font License 1.1).

== Installation ==

1. Download fuchi-glazing.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/fuchi-glazing.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Fuchi Glazing.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, a sample post with category and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

Optional forms: the contact and waitlist sections use a dynamic form block (inc/shippress-forms.php). Without a form plugin the contact page keeps an email button and the waitlist form shows an email field with a submit button that opens the visitor's email app with the request ready to send (the theme sends nothing itself). With Contact Form 7 or WPForms (contact), or MailPoet (explicit form ID) or Mailchimp for WP (newsletter), that plugin's form is shown instead.

Scroll effects: assets/sp-scroll.css and assets/sp-scroll.js (reveal, stagger, parallax). They respect prefers-reduced-motion and show everything without JavaScript.

WooCommerce: support is declared; the theme works fully without it.
