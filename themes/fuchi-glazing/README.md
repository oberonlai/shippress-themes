# Fuchi Glazing

Landing theme for a commercial glazing contractor (survey and quote): a solid slate panel with a slanted edge beside one framed photograph and a three-fact info-bar, a two-tier header with a solid current block and an outlined circle-arrow request box, a four-by-two square catalogue with light centred headings, dated ledger rows, an asymmetric project masonry and a full-width price table. Home is one long conversion page with an anchor menu and one repeated request: Book a survey.

See `brand.md` and `brand/design-spec.md`.

- Fonts: Onest and DM Sans (OFL-1.1), loaded through `theme.json` fontFace.
- Forms: contact and waitlist sections use the shared dynamic form block (`inc/shippress-forms.php`).
- Scroll effects: `assets/sp-scroll.css` and `assets/sp-scroll.js` (reveal up, wipe, parallax).
