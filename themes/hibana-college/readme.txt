Hibana College is a dark, photo-led block theme for a welding and metal-fabrication trade school for adults changing jobs. It presents the six-month course, the workshop week, instructors, graduate stories, fees and admissions in a calm, specific voice. Ground, type and panels follow the stage-one design spec, with low-key workshop photography and no job promise.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download hibana-college.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hibana-college.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hibana College.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, the menu, and sets the front page. It never changes or deletes anything you wrote.

The college, its people, employers and fees are fictional.
