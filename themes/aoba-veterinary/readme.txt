Aoba Veterinary Clinic is a Fairhaven practice for dogs and cats, founded in 2014 by Dr. Elena Varga. The site explains a visit from the 30-minute first consultation to a nurse’s call within 48 hours, and lists fees in US dollars with a written estimate before treatment. Three recovery stories are told as single cases, without promising the same result for every animal.

== Description ==

A WordPress block theme from ShipPress. See README.md for the design notes, templates and patterns, and brand.md for the fictional clinic the sample content is written for.

== Installation ==

1. Download aoba-veterinary.zip from the theme's release.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Aoba Veterinary.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php, driven by demo-content.json): it creates its pages with all their text and images, the menu, and sets the front page. Then you only change the text and swap in your own pictures. It never changes or deletes existing content, and running it again only adds what is missing. If the automatic setup did not run, use the "Import demo content" button shown in wp-admin, or run: wp shippress demo-import

Booking is by phone or email; no plugin is needed. The theme declares WooCommerce support but works the same without it.
