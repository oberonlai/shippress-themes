# Hone Orthopedics

Block theme for an orthopedic and sports injury clinic (type health). Stage 1: home page, English.

Signature techniques: tall rounded portrait strip bleeding off both edges, thick round-capped ribbon over a pale disc and dark arc, 3:4 photo cards with a notched arrow tab. Source Serif 4 and Source Sans 3. Colours: ground #F7F9FA, panel #E8EEF2, slate #3E5566, ribbon #8DB3CC, ink #2E3A44.
