Hone Orthopedics: a block theme for an orthopedic and sports injury clinic. A cool off-white ground with a slate primary, a first screen of tall rounded portraits bleeding off both edges, a thick round-capped ribbon stroke over a pale disc and a dark arc, and tall photo cards with a notched arrow tab. Works without any plugin. WCAG AA colours; no entrance animations.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). Stage 1 contains the home page (English).

== Installation ==

1. Download hone-orthopedics.zip from the releases page.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hone Orthopedics.

On activation the theme creates its pages with their text and images, three journal entries, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The clinic, its clinicians, addresses and prices are fictional. All photographs are generated images.
