# Waku Exhibits

Waku Exhibits is a calm, documentary-style WordPress landing theme engineered for exhibition stand builders and structural design workshops. Featuring photo-filled statement typography, edge-flush hall showcases, and transparent pricing structures, it focuses visitor attention on hall planning and craftsmanship. A single repeated quote inquiry workflow connects exhibitors directly with workshop planners.

## Structure
- `patterns/front-*.php`: the home sections (hero, statement, halls, planning hour, hall band, prices, stories, request band); `head-bar.php` and `foot-main.php`: header and footer content.
- `templates/`: front page, page, single, posts page, archive, category, tag, search and 404.
- `inc/i18n/<lang>.php`: the theme strings; `demo-content*.json`: sample content.
- `assets/sp-scroll.css`, `assets/sp-scroll.js`: scroll reveals and parallax (CSS first, reduced-motion safe).
- Photos: `assets/images/` (AI-generated, GPL-2.0-or-later / CC0). See `readme.txt` for the list.

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
