Kensa Laboratory is a block theme for a materials testing laboratory working in concrete, rebar, cores and chemistry. The home page is a single-column landing: a documentary photo strip, eight open tests, a sample log and a fee table, with a booking path for submissions. Nine inner pages (tests, how to send, fees, lab, case notes, sample log, FAQ, booking, waitlist), thanks, privacy and terms pages and one article ship as sample content. Founded-in-copy is 2009, at Unit 4, 18 Harbour Works Road, Northgate, with reports in two working days.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download kensa-laboratory.zip from the releases page of https://github.com/oberonlai/shippress-themes
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kensa Laboratory. On activation it creates the home page and the menu (inc/demo-import.php).

The laboratory, its people, address and prices are fictional.
