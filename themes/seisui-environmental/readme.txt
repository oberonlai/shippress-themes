Seisui Environmental is a business theme for a consultancy that advises landowners and municipal clients on water, soil and habitat. The demonstration copy is set in Alder Bridge on the River Wend, where the practice was founded in 2009 and still keeps office hours Monday to Friday, 08:30–17:30. Fees are shown in USD, and the monitoring ledger uses the practice’s own site codes.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes and patterns.

== Installation ==

1. Download seisui-environmental.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/seisui-environmental.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Seisui Environmental.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works with or without WooCommerce.

The practice, its people, sites, addresses, telephone number and prices are fictional.
