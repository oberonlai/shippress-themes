# Seisui Environmental

Block theme for an environmental consultancy (landowners and municipal clients). Stage 1: home page in English.

- Home: `front-hero`, `front-strip` (marquee), `front-intro`, `front-services` (parallax band), `front-ledger`, `front-process` (pinned photo), `front-fees`, `front-notes`, `front-people`, `front-contact`.
- Techniques: ghost word behind every heading, parallax photo band behind white cards, first screen cropped by the right edge.
- Scroll effects: `assets/sp-scroll.css` / `sp-scroll.js` (sp-reveal, sp-stagger, sp-count, sp-parallax, sp-marquee).
- Fonts: Spectral + IBM Plex Sans via theme.json fontFace.
