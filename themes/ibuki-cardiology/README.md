# Ibuki Cardiology

Ibuki Cardiology is a calm, block-based WordPress theme designed for independent outpatient cardiology clinics and healthcare practices. Built with a structured narrative flow, full-bleed documentary imagery, and precise typography, it presents scheduled weekday clinics, timed first visits, and transparent fee tables with clarity and quiet confidence. The theme features custom editorial patterns, responsive block layouts, and accessible styling without relying on external libraries.

## Structure
- `patterns/front-*.php`: the eleven home sections (hero, problem, clinics, ticker, first visit, proof, fees, follow-up, people, news, close).
- `patterns/tpl-*.php`: page, single post, archive, search and 404 bodies; `templates/`: the block templates.
- `assets/sp-scroll.*`: reveal, stagger, parallax and marquee classes (`sp-*`), no third-party scripts.
- `inc/demo-import.php`: sets up the sample pages and posts on activation; `demo-content.json`: the sample content.
- Photos: `assets/images/demo/` (AI-generated, GPL-2.0-or-later / CC0). See `readme.txt` for the list.

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
