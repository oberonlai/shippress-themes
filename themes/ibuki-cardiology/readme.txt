Ibuki Cardiology is a calm, block-based WordPress theme designed for independent outpatient cardiology clinics and healthcare practices. Built with a structured narrative flow, full-bleed documentary imagery, and precise typography, it presents scheduled weekday clinics, timed first visits, and transparent fee tables with clarity and quiet confidence. The theme features custom editorial patterns, responsive block layouts, and accessible styling without relying on external libraries.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download ibuki-cardiology.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/ibuki-cardiology.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Ibuki Cardiology.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, six news posts with four categories and five tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works without WooCommerce.

The clinic, its people, address, telephone number and prices are fictional.
