Susugi Wash is a calm, single-column WordPress landing theme designed for compact commercial kitchens and preorder product showcases. Built around a precise 50/50 split hero, corner-bracket calls to action, and full-bleed staggered photo galleries, it presents product specifications and fitting timelines with understated clarity. Features responsive typography in Albert Sans and Manrope, accessible block patterns, and seamless multilingual support without external plugin dependencies.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download susugi-wash.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/susugi-wash.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Susugi Wash.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php, driven by demo-content.json): it creates its pages with all their text and images, the menu, and sets the front page. Then you only change the text and swap in your own pictures. It never changes or deletes existing content, and running it again only adds what is missing. If the automatic setup did not run, use the "Import demo content" button shown in wp-admin, or run: wp shippress demo-import
