Rinrin Cycle Tours is a calm, documentary theme for guided coast cycling operators and tour catalogues. A full-bleed quay photograph with a tall vertical headline, a sideways strip of tour spec cards, stacked photograph strips and a grade ledger give practical route details a quiet, photographic home. Built with block patterns, responsive typography and full site editing support.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page opens on a full-bleed high-angle quay photograph with a tall vertical headline, then runs through an About block on a blurred photograph, a sideways strip of five tour spec cards, a framed "riding day" band, two stacked photograph strips (bike hire, luggage transfer), a four-row grade ledger, one way to book and the journal. See README.md for the design notes.

== Installation ==

1. Download rinrin-cycletours.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/rinrin-cycletours.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Rinrin Cycle Tours.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, journal entries with categories and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The scroll effects (assets/sp-scroll.css and sp-scroll.js) respect prefers-reduced-motion and show the final state without JavaScript. The newsletter and contact slots use Contact Form 7, WPForms, MailPoet or Mailchimp for WP when active; without a plugin they fall back to an email link.

The company, its people, address, telephone number, email and prices are fictional.
