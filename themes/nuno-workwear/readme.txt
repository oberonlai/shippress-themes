Nuno Workwear is a documentary, sans-serif WordPress block theme designed for workwear and safety clothing shops, repair workshops, and trade outfitters. Built around a split-navigation layout, dashed column guides, and high-contrast ink-and-ground section rhythms, it operates smoothly as a standalone business catalogue or alongside WooCommerce. The design provides structured templates for trade-specific workwear specs, alteration price lists, and crew fitting services.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download nuno-workwear.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/nuno-workwear.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Nuno Workwear.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, the inner pages and the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The shop, its people, address, telephone number and prices are fictional.
