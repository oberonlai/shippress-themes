A calm, serif WordPress theme designed for artisanal chocolatiers and cocoa cafes, inspired by minimalist Japanese patisserie sites. Built around an hour-keyed sticky photo plate, staggered outline card walls, and vertical phrase strips, it highlights small-batch morning tempering and afternoon counter service. Includes booking-led layouts for seated cocoa tastings, weekend cake collections, and seasonal single-origin price lists.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page opens on a centred framed photo window on white with three dotted vertical phrase strips hanging beside it, a hand-drawn tempering curve, the headline "Tempered at ten." and a row of bean origins. Below it a half-viewport photo plate stays flush left while the photograph changes with each hour of the making day, then a pale days panel, a staggered wall of outline menu cards, a parallax marble band, a dotted accordion for cake orders, story rows, the visit details and a monthly letter. Scroll effects (soft rises, card stagger, parallax) use the small sp-scroll script in assets/ and respect prefers-reduced-motion. The optional newsletter and contact slots work without any plugin and use Contact Form 7, WPForms, MailPoet or Mailchimp for WP when present.

== Installation ==

1. Upload the theme and activate it under Appearance > Themes.
2. On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page, the journal with sample posts and the menu, and sets the front page and posts page. Use Tools > Import demo content to run it again.
3. Edit everything in the block editor; the sections are block patterns in the "Kaoru Cocoa" category.

The shop, its people, address, telephone number and prices are fictional.
