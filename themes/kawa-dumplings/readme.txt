Kawa Dumpling House is a WordPress theme for a soup dumpling house with dine-in, takeaway and frozen packs across three branches. The front page uses a three-panel cover, sentence rows and a branch index with hours, basket prices and Friday restocks. Copy stays with the fold, the counters and the order-ahead cut-offs.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page opens on three flat panels edge to edge: a cream paper column inside a pleat-rim double frame with the headline and one order-ahead button, a flat clay index of the three branches with hours, dotted leaders, a marker and a ticker, and a full-height documentary photograph that moves slower than the page, with a scalloped badge that rattles on the seam. Below: a fold story as one sentence per dashed row beside a sticky photograph, branch tickets with pill labels, a frozen shelf, a clay order-ahead panel, a parallax glass band, a price ledger, the journal and a steam letter form. Scroll effects (rise, ticker, parallax) use the small sp-scroll script in assets/ and respect prefers-reduced-motion. The optional newsletter and contact slots work without any plugin and use Contact Form 7, WPForms, MailPoet or Mailchimp for WP when present.

== Installation ==

1. Download kawa-dumplings.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kawa-dumplings.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kawa Dumpling House. On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): the home page, inner pages, journal with sample posts and the menu. Use Tools > Import demo content to run it again.
4. Edit everything in the block editor; the sections are block patterns in the "Kawa Dumpling House" category.

The house, its people, addresses, telephone number and prices are fictional.

== Forms ==

Order ahead and Contact: recommended Contact Form 7 fields are name (required), email (required), phone, branch (select: Harbour Street, Linden Market, Station Arcade), pickup day, pickup time (select: lunch 12:00-14:00 or dinner 17:30-20:00), order, large order checkbox, note and consent. Without a plugin the page shows an "Email your order" button that opens your email app.
