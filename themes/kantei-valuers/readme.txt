Kantei Valuers is a long-form landing WordPress theme for commercial property valuers, surveyors and appraisal practices. One conversion page follows an instruction from a sixty-minute site hour to a signed report, with a full-bleed documentary photograph, two touching instruction panels, a stacking site-hour card deck, report rows, a fee table and a single Request an appraisal call to action. Five-language compatible.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download kantei-valuers.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kantei-valuers.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kantei Valuers.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, five news entries with two categories and seven tags, the top menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. WooCommerce is supported but not needed.

Languages: the sample content comes in English (demo-content.json) and, in the full release, Traditional Chinese, Japanese, French and German. The importer uses the `shippress_demo_lang` option (set by ShipPress from its interface language), else the site language.

Scroll effects: assets/sp-scroll.css and assets/sp-scroll.js (a small script loaded in the head, no libraries). Content stays visible without JavaScript and with reduced motion.

The practice, its people, address, telephone number, figures and fees are fictional.
