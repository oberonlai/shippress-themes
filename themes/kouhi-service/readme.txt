Kouhi Service is a calm, typography-led WordPress landing theme designed for workplace coffee services and local equipment placements. Built with clean sans-serif typography, subtle documentary imagery, and structured block layouts, it presents plans, tasting calendars, and service details with clarity. Features sticky header navigation, scheduled tasting visit calendars, and responsive pricing tables.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes and patterns.

== Installation ==

1. Download kouhi-service.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kouhi-service.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kouhi Service.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page and twelve inner pages (service, tasting visit, plans, machines, offices, about, FAQ, contact, waitlist, privacy, terms, thanks), the journal with one article, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The company, its address, telephone number and prices are fictional.
