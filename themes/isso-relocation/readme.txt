Isso Relocation is a calm, single-column WordPress landing theme built for corporate office moving crews and logistics providers. Designed around a split first screen, clear multi-phase timelines, and structured pricing tables, it presents commercial relocation workflows with quiet authority. It includes dedicated templates for floor planning guides, move case studies, technical FAQs, and quote intake.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download isso-relocation.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/isso-relocation.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Isso Relocation.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with its text and images, the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The company, its people, prices and telephone number are fictional.
