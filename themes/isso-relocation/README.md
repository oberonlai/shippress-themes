# Isso Relocation

Block theme for an office-moving crew (landing track). Home (en): split first screen (dark photo left, grey haze right with a framed 3:4 photo between two vertical lines, seam-crossing wordmark with rising letters, fixed side tab), 96 px light-sans section titles with a half-width text column, a full-bleed parallax photo with two overlapping photos, five-phase text row, figure cards, hours rail, one move, price table, crew, questions and one repeated quote request.

Scroll effects: `assets/sp-scroll.css|js` (reveal, stagger, count, marquee, parallax) — off for reduced motion.

Photos: 16 film-grain photographs in `assets/images`. Pages (en): home, method, prices, moves, planning, crew, faq, request-a-quote, updates, thanks, privacy, terms, journal and one move story post; every inner page opens with the split page head (photo left, haze right, vertical line, seam-crossing wordmark) and Method, Planning, Crew and the story carry the three-photo overlap with parallax. The main menu links to the real pages. Languages: en only so far; zh-TW, ja, fr, de are stage 2.
