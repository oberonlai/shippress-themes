Asaoka Screening is a block theme for a corporate health screening centre that books employee medicals for small companies. The home page opens on a split hero with a mist wave and a tabbed notice card, then five scoop-corner photo tiles, ruled rows for how findings are explained, a parallax photo band, company stories, packages and open dates. Founded-in-copy is 2009, at 14 Linden Row, Harbour District.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download asaoka-screening.zip from the releases page of https://github.com/oberonlai/shippress-themes
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Asaoka Screening. On activation it creates the home page, ten inner pages, the journal with one article and the menu (inc/demo-import.php).

The centre, its people, address and prices are fictional.
