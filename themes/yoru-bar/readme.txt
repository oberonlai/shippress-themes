Yoru Bar is a dark, cinematic WordPress theme designed for reservation-only cocktail bars and intimate hospitality spaces. Inspired by the quiet discipline of craft bar culture, it features full-viewport split panels, striking typography, and a booking-led structure tailored for counter seating. Built with fine typography in EB Garamond and Work Sans, it presents seasonal cocktail lists, room schedules, and dispatches with understated elegance.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download yoru-bar.zip from the ShipPress themes releases.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme and install the zip.
3. Activate Yoru Bar. On activation it creates the home page, the inner pages, the Notes page with four sample posts and the menu (inc/demo-import.php). It never changes what you wrote.

The bar, people, address, telephone number and prices are fictional.
