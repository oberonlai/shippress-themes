# Utsushi Films

A dark, low-key documentary portfolio block theme for an independent film director's studio: a film index crossing a centred framed window, an asymmetric case wall in index-row voice and the single white "Propose a film" box.

## Notes
- Fonts: Space Grotesk (display) and Inter Tight (text), loaded through `theme.json` `fontFace`.
- Scroll effects: `assets/sp-scroll.css` / `assets/sp-scroll.js` (parallax on the first-screen window, the harbour band and the crew window; fade-up with stagger; a wipe panel).
- Forms: `inc/shippress-forms.php` (dynamic `shippress/form` block with a mailto fallback).
- Patterns: `utsushi-films/front-*` build the home page; `header-main` and `footer-main` back the template parts.
