Senbatsu Partners is a WordPress landing theme designed for retained executive search firms, boards, and leadership consultancies. Built around a single-column longform layout with anchor navigation and clear house rules, it presents mandates, partner bios, transparent fees, and process timelines with calm typographic clarity. The theme features documentary photography, responsive fee tables, and subtle scroll motions for professional corporate presentation.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). On activation it sets itself up as a ready-to-use website (inc/demo-import.php): pages with text and images, case letters with categories and tags, the menu, and the front page and posts page. It never changes or deletes anything you wrote.

Contact and newsletter sections use an optional form slot (inc/shippress-forms.php): Contact Form 7 or WPForms when active for contact, MailPoet or Mailchimp for WP for the newsletter; without a plugin the slot shows a mailto fallback and a visible email field.

The firm, its people, address and fees are fictional.

== Installation ==

1. Download senbatsu-partners.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/senbatsu-partners.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Senbatsu Partners.
