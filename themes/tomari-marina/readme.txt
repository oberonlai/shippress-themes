Tomari Marina is a block theme for a small-boat marina on the North Quay of Wrenhaven, with 100 berths and a season from 1 April to 31 October. The home page is booking-led: a low-key harbour photograph, the morning round at 06:30, and season fees in EUR. Templates carry the berths, the crew, the logbook and the office in English, Traditional Chinese, Japanese, French and German.

== Description ==

A WordPress block theme from ShipPress. See brand.md for the fictional marina the sample content is written for. Sample content is imported on activation (inc/demo-import.php, driven by demo-content.json) and never changes or deletes existing content; if it did not run, use the "Import demo content" button in wp-admin or run: wp shippress demo-import

== Installation ==

1. Download tomari-marina.zip from the theme's release.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Tomari Marina.
