== Description ==

Kiban Structural is a calm, high-contrast WordPress theme designed for structural engineering practices and technical studios. Built with an eight-column construction grid, low-key monochrome styling, and sticky-media project timelines, it presents calculations, drawings, and built works with quiet authority. The home page opens on a white sheet with an eight-column hairline grid. A stadium-shaped photograph sits over a giant black wordmark that runs past both screen edges, with the tagline spread across the bottom. Scrolling opens it into a dark full-bleed photograph with rounded top corners and a slow parallax. Next come the six-stage process beside a sticky photograph, tilted line-diagram service cards, four projects, the fee table, the team and a strip of working standards. Albert Sans for headings, Instrument Sans for reading.
