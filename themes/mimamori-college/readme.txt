Mimamori College is a calm, purposeful WordPress block theme crafted for caregiver training colleges and adult vocational institutions. Designed with clear typography, soft natural tones, and dedicated layouts for courses, practice routines, and residential placements. Built for full site editing with thoughtful responsive behaviour, high-contrast readability, and comprehensive block patterns.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download mimamori-college.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/mimamori-college.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Mimamori College.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, the menu, and sets the front page. It never changes or deletes anything you wrote.

The college, its people, partner homes, courses and fees are fictional.
