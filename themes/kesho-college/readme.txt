Kesho College is an editorial WordPress theme designed for hairdressing and beauty training academies. Featuring a split-screen aesthetic, edge-to-edge drifting hero portrait panels, and a disciplined day-schedule layout, it highlights vocational craft through calm typography and high-key photography. Built with complete course listings, tuition tables and a student salon, the theme functions fully without requiring WooCommerce.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md and brand/design-spec.md for the design notes.

== Installation ==

1. Download kesho-college.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kesho-college.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kesho College.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images, the menu, and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The college, its people, address and prices are fictional.
