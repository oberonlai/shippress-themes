Hakari Course is a calm, responsive WordPress theme designed for online food-safety supervisor courses powered by Tutor LMS and WooCommerce. It combines high-key kitchen photography, tilted card motifs, and clear tabular cohort pricing into a structured six-week course presentation. Built for culinary academies, it provides shift leads and kitchen supervisors with a focused, distraction-free learning experience.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the fictional brand brief.

== Installation ==

1. Download hakari-course.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hakari-course.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hakari Course.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images and the anchor menu. It never changes or deletes existing content. If the automatic setup did not run, use the "Import demo content" button in wp-admin, or run: wp shippress demo-import

The company, people, address and prices are fictional.
