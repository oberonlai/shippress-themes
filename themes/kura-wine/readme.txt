Kura Wine is a calm, editorial WordPress theme designed for independent wine merchants, cellars, and boutique bottle shops. Built with full WooCommerce integration, it pairs documentary film photography and refined serif typography with atmospheric storytelling, shipment logs, and seasonal tasting announcements. The theme renders seamlessly as an evocative digital storefront or as a quiet cellar catalogue when e-commerce is disabled.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download kura-wine.zip from the ShipPress themes releases.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme and install the zip.
3. Activate Kura Wine. On activation it creates the home page, the Bottles page, the menu and, with WooCommerce active, six sample bottles (inc/demo-import.php, inc/woo-import.php). It never changes what you wrote.

The winery, people, address, telephone number and prices are fictional.
