# Kura Wine

WooCommerce store theme for an independent wine merchant: slate-ink ground, umber wash, Fraunces and Karla. Stage 1 holds the home page (full-bleed cross-fading film cover, scattered About, shipments with vertical region titles, bottles, half-bleed split, Friday table, umber visit band).

## Structure
- `patterns/front-*.php`, `visit.php`, `head-bar.php`, `foot-main.php`; `templates/`; `inc/i18n/en.php` (theme strings); `demo-content.json`.
- Scroll effects: `assets/sp-scroll.css|js` (unchanged ShipPress copy).

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`. License: GPL-2.0-or-later.
