Hazuki Instruments is a calm, sans-serif WordPress theme crafted for musical instrument shops, featuring asymmetric masonry layouts and dedicated WooCommerce integration. Built around an unhurried fitting philosophy, it provides structured floor directories, private trial booth reservations, and clear repair service price lists. Designed with balanced steel tones and refined typography, it delivers an honest, tactile storefront experience across all devices.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download hazuki-instruments.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hazuki-instruments.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hazuki Instruments.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with their text and images, the floor-notes posts and the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The shop, its staff, address, telephone number and prices are fictional.
