# Katachi Ergonomics

Katachi Ergonomics is a landing WordPress theme for a workplace ergonomics consultancy that watches a working desk before it recommends a change. The home page is one long conversion page toward a single booking, the readiness review.

## Structure
- `patterns/kv.php`: full-bleed pale photograph (parallax) with a wide-tracked headline, three observation markers and a white card docked at the lower left.
- `patterns/includes.php`: three equal abutting columns (4px gaps) with a photograph on top, a pale panel and white arrow tiles.
- `patterns/visit.php`, `patterns/people.php`: offset photograph rows flush to the viewport edge, with an overlapping card or a white notch.
- `patterns/band.php`, `fees.php`, `cases.php`, `book.php`, `openings.php`: parallax band, fee table, field notes, booking band, newsletter slot.
- `assets/sp-scroll.css`, `assets/sp-scroll.js`: scroll reveal and parallax (unchanged shared files). `assets/shippress-forms.css`, `inc/shippress-forms.php`: optional forms (mailto fallback without plugins).
- `inc/i18n/<lang>.php`: theme strings; `demo-content.json`: sample content.

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
