Yukishiro Chalet is a calm WordPress theme designed for ski-in chalets and mountain hotels situated right at the foot of the gondola. Featuring eighteen rooms, winter ski packages, and summer hiking stays, it pairs full-bleed alpine photography with refined typography and practical booking details. Built for speed and clarity, the layout offers seamless package comparisons, equipment room highlights, and serene mountain storytelling.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes. Fonts: Cormorant Garamond (display), Lato (text), and Noto Serif TC / Noto Serif JP (zh-TW and ja display subsets), all under the SIL Open Font License.

== Installation ==

1. Download yukishiro-chalet.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/yukishiro-chalet.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Yukishiro Chalet.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The chalet, its people, village, address, telephone number and prices are fictional.

== Forms ==

The Snow letter section on the home page uses the shared form slot (inc/shippress-forms.php). Without a form plugin it shows a real email field and a submit button that opens the visitor's email app with the address; the notice says plainly that the visitor is not subscribed until that message is sent. MailPoet or Mailchimp for WP are used when active.
