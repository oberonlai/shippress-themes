Kakeru Run is a quiet, grid-based WordPress theme built for running shoe fitting shops and specialist footwear stores. Designed around ruled editorial columns, high-key photography, and WooCommerce integration, it highlights footwear lasts, video gait sessions, and technical specifications. The layout pairs clean typography with responsive spec tables to present running footwear with calm precision.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The page is one continuous ruled grid between two outer rails: a three-cell split header, a hexagon-outline stage, 1:1 specimen tiles on coloured paper, 2+1 info rows with a big outline pill and a clay slash cell, a parallax gait-lab photograph and one brown order band. Scroll effects (grid lines drawing in, cell content rising, parallax) use the small sp-scroll script in assets/ and respect prefers-reduced-motion.

== Installation ==

1. Download kakeru-run.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kakeru-run.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kakeru Run.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page and the inner pages (Shoes, Lasts, Gait session, About, Contact, Newsletter, Stories) with their text and images, two sample posts and the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works without WooCommerce.

The shop, its people, address, telephone number and prices are fictional.
