Kaban Luggage is a quiet, refined WordPress store theme designed for bespoke luggage fitting and travel goods shops. Built with full WooCommerce support, it combines low-key documentary imagery, tactile paper textures, and structured product specification catalogues. The design features elegant typography, smooth scroll reveals, and dedicated layouts for workshop services and personal fittings.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes.

== Installation ==

1. Download kaban-luggage.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kaban-luggage.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kaban Luggage.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, four stories with two categories and five tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. With WooCommerce active it also adds five sample products with three categories and five tags (inc/woo-import.php); without WooCommerce the theme works as a plain site.

The shop, its products, address, telephone number and prices are fictional.
