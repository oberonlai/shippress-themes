Asagiri Hotel is an editorial WordPress theme designed for airport hotels and transit hospitality, structured around the progression of a single night. Built with classic serif typography, low-key documentary photo frames, and calm responsive block patterns, it presents twenty-four-hour desk operations, room selections, shuttle schedules, and late check-in hold policies with quiet clarity.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download asagiri-hotel.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/asagiri-hotel.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Asagiri Hotel.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, six news posts with two categories and six tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works without WooCommerce.

The hotel, its people, address, telephone number and prices are fictional.
