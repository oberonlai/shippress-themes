# Asagiri Hotel

Asagiri Hotel is an editorial WordPress theme designed for airport hotels and transit hospitality, structured around the progression of a single night. Built with classic serif typography, low-key documentary photo frames, and calm responsive block patterns, it presents twenty-four-hour desk operations, room selections, shuttle schedules, and late check-in hold policies with quiet clarity.

Home and inner-page patterns (English demo content; other languages follow). Home patterns: front-hero, front-intro, front-rooms, front-checkin, front-shuttle, front-clock, front-departure, front-notes, front-close. Design notes in `brand/design-spec.md` and `brand.md`.
