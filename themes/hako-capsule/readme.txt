Hako Capsule is a calm, typographic WordPress block theme for station-front capsule hotels, transit hostels and compact hospitality spaces. Inspired by contemporary venue architecture, it features clean one-pixel ink borders, tabular comparison layouts and responsive full-bleed photography. Built for the block editor with full site editing support, fast performance and quiet editorial precision.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page is built from patterns: a stage photograph with a Tonight card, a narrow story column, a five-cell pod wall, a comparison table, a parallax shower band, notched numeral cards, ruled house rules, night-desk stories, a newsletter slot and an ink booking band.

Fonts: Geist (headings) and Inter Tight (reading text), both under the SIL Open Font License 1.1. Chinese headings use a Noto Sans TC subset (OFL 1.1). Japanese headings and body use a Noto Sans JP subset (OFL 1.1).

== Installation ==

1. Download hako-capsule.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hako-capsule.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hako Capsule.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with their text and images, a journal post with a category and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

Optional forms: the newsletter box uses a small dynamic block. With MailPoet or Mailchimp for WP active, their form is shown; without a plugin it shows an email field that opens your mail app (you are not subscribed until you send the message). The booking page uses Contact Form 7 or WPForms when present, and a mail button otherwise.

Scroll effects use the bundled sp-scroll files (assets/sp-scroll.css and assets/sp-scroll.js); they respect prefers-reduced-motion.

The hotel, its people, places and prices are fictional.
