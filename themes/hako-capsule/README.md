# Hako Capsule

A WordPress block theme for a station-front capsule hotel. White page ruled in 1px ink lines; wordmark band over a framed sticky nav; a hanging ink booking slab; stage photograph with a Tonight card; pod-bay wall; comparison table; notched numeral cards; ruled house rules. See brand.md and brand/design-spec.md.

Fonts: Geist and Inter Tight (OFL-1.1), in assets/fonts. Scroll effects: assets/sp-scroll.css and assets/sp-scroll.js (reveal, wipe, stagger, parallax). Optional forms: inc/shippress-forms.php (newsletter and contact slots).
