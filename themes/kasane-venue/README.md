# Kasane Venue

Kasane Venue is a calm, editorial WordPress theme created for a daylit wedding venue in a historic riverside wool-exchange hall. Rooted in organic blob windows, alternating edge-bleeding imagery, and delicate pastel washes, it pairs Fraunces serif headings with clean Figtree typography for an unhurried, booking-led experience.

## Structure
- `patterns/front-*.php`: the twelve home sections (hero, opening, house, four rooms, day, stories, people, fees, viewing); `header-main.php`, `footer-main.php`.
- `templates/`: front page, page, index, home, archive, single, search, tag, 404.
- Photos: `assets/images/` (AI-generated, GPL-2.0-or-later / CC0). See `readme.txt`.
- English only for now (home); inner pages and zh-TW, ja, fr, de follow.

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
