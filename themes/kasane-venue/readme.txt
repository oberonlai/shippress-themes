Kasane Venue is a calm, editorial WordPress theme created for a daylit wedding venue in a historic riverside wool-exchange hall. Rooted in organic blob windows, alternating edge-bleeding imagery, and delicate pastel washes, it pairs Fraunces serif headings with clean Figtree typography for an unhurried, booking-led experience.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download kasane-venue.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kasane-venue.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kasane Venue.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates the home page with all its text and images and sets the front page. It never changes or deletes anything you wrote, and running it again creates nothing twice. Works without WooCommerce.

The venue, its people, address and prices are fictional.
