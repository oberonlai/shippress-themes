# Nagisa Grill

Nagisa Grill — an editorial block theme for a coastal seafood restaurant that serves one boat's catch in a single dinner service. The home page opens on a full-bleed, dimmed film-grain photograph with the name spread edge to edge in light Fraunces and a hairline info bar with two outlined tabs, under an overlay header (menu, lockup, book pill). Three thin wave lines mark every section label, divide the day rows and table rules, and close the footer. A near-black scene holds an offset pair of photographs (28% and 72%, the large one 120 px lower), followed by a slate band with three full-bleed plate panels. Fraunces for headings, Source Serif 4 for reading. Sample content in English with the form slots for contact and newsletter; works without any plugin. Parallax on the first screen, the photo pair and the visit band; reveal and stagger on day rows and panels; all motion is off for reduced-motion users.

## Structure
- `patterns/front-*.php`: the eight home sections (kv, concept, day, kitchen, tables, plates, journal, visit).
- `patterns/header-main.php`, `footer-main.php`, `page-*.php`, `tpl-*.php`: header, footer, visit and newsletter pages, search and 404.
- `inc/i18n/en.php`: theme strings; `demo-content.json`: sample pages, menu and journal posts.
- Photos: `assets/images/` (AI-generated, GPL-2.0-or-later / CC0). See `readme.txt` for the list.

Design notes: `brand.md`, `brand/`.
