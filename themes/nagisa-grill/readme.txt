Nagisa Grill is an editorial magazine WordPress theme designed for coastal seafood restaurants and daily-catch kitchens. Built around a calm day-schedule layout with serif typography and full-bleed imagery, it reflects the unhurried rhythm of one boat and one dinner service. Lightweight and block-first, it offers dedicated patterns for daily service times, kitchen notes, and table reservations without requiring extra plugins.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). On activation it sets itself up as a ready-to-use website (inc/demo-import.php): pages with text and images, journal entries with categories and tags, the menu, and the front page and posts page. It never changes or deletes anything you wrote.

Contact and newsletter sections use an optional form slot (inc/shippress-forms.php): Contact Form 7 or WPForms when active for contact, MailPoet or Mailchimp for WP for the newsletter; without a plugin the slot shows a mailto fallback and a visible email field.

The restaurant, its people, address and prices are fictional.

== Installation ==

1. Download nagisa-grill.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/nagisa-grill.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Nagisa Grill.
