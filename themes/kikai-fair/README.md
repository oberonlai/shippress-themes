# Kikai Fair

A landing theme for a woodworking-machinery trade fair: diagonal-split hero with a three-photo crossfade, twin audience bars, a near-black faceted card strip, numbered value rows with a rotated label and an ochre day line, and a parallax access band.

Fonts: Hanken Grotesk (headings), Instrument Sans (body), Noto Sans TC / JP for Chinese and Japanese. Scroll effects: `assets/sp-scroll.css` / `sp-scroll.js` (reveal, stagger, count, parallax). Forms: `inc/shippress-forms.php` (dynamic `shippress/form` block).
