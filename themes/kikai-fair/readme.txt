Kikai Fair is a calm, documentary landing theme designed for trade fairs, industrial machinery exhibitions, and technical community events. Inspired by modern exhibition hall aesthetics, it features faceted dark bands, high-contrast ochre accents, structured production timelines, and comprehensive multi-language support. Built with clear typography and strict full-width layouts, the theme presents running machinery, stand directories, and visitor registration with quiet precision.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download kikai-fair.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/kikai-fair.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Kikai Fair.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, news posts with a category and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

Forms: the early-access section uses a small dynamic block (inc/shippress-forms.php). With MailPoet or Mailchimp for WP configured it shows that form; without a plugin it shows a real email field and a button that opens your email app with the address (nothing is subscribed until the email is sent).

The fair, its people, venue, prices and dates are fictional.
