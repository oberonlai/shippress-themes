Hibari Flight is a calm, documentary-styled WordPress theme designed for flight schools, aerodromes, and regional aviation training centres. Built around clean editorial typography, full-screen process strips, and high-key documentary photography, it presents flight training with clarity, warmth, and quiet professionalism. It includes full template support for lesson walkthroughs, fleet specifications, and transparent fee tables.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes.

== Installation ==

1. Download hibari-flight.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/hibari-flight.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Hibari Flight.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, six stories and field notes with two categories and four tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The school, its people, address, telephone number and prices are fictional.
