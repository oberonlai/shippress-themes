Homura Safety is a calm, responsive WordPress theme designed for fire-safety compliance consultancies and workplace inspection services. Inspired by high-contrast technical publications, it features signature slanted bar hero typography, docked quick-link navigation, and structured findings report templates. Built with clean block layouts and accessible sans-serif typography, it delivers a clear, professional presentation for technical advisory firms.

== Description ==
A block theme for a fire-safety compliance consultancy. The home page is one long conversion page: a full-bleed low-key kitchen photograph with white slanted bars spelling CHECK, a docked four-cell link strip, chestnut photo tiles with a triangular notch pointing into white text panels, a parallax corridor band that lays out the visit, a findings excerpt, a fixed fee table and a single booking band.

= Fonts =
* Libre Franklin (headings, labels, prices), SIL Open Font License 1.1.
* Source Sans 3 (body text), SIL Open Font License 1.1.

= Images =
The sample photographs were generated for this theme. They contain no text, logos or real people.

= Forms =
The newsletter and contact forms use a dynamic block that shows a Contact Form 7, WPForms, MailPoet or Mailchimp for WP form when one is active. Without a plugin the newsletter form still has an email field and a submit button that opens your email app with the address filled in; nothing is stored by the theme.
