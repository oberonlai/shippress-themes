Satei Adjusters is a quiet, horizontal-strip WordPress landing theme crafted for independent loss-adjusting desks and specialised consultancy practices. Flooded in muted mauve tones with refined sans typography, it pairs sticky split-screen narratives and hairline section openers with structured case records and fixed-fee schedules. Designed for deliberate restraint, the layout highlights evidence-first professionalism with responsive precision.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download satei-adjusters.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/satei-adjusters.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Satei Adjusters.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php, driven by demo-content.json): it creates its pages with all their text and images, the menu, and sets the front page. Then you only change the text and swap in your own pictures. It never changes or deletes existing content, and running it again only adds what is missing. If the automatic setup did not run, use the "Import demo content" button shown in wp-admin, or run: wp shippress demo-import
