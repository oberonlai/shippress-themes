Yanagi Hygiene is a calm, documentary landing theme for commercial pest-control and hygiene firms. A full-bleed ceiling-void photograph ends in a white commercial skyline and a twelve-month rail with four visit markers, followed by a building cross-section with plus pills, a sticky photograph beside four timed chapters, a parallax band, a framed logbook panel, fees and a pentagon request tab. Manrope and Source Sans 3. Sample content in English.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). Fonts: Manrope for headings and Source Sans 3 for reading (both OFL-1.1, bundled in assets/fonts). Traditional Chinese headings use Noto Sans TC; Japanese headings use Noto Sans JP (both OFL-1.1, subset files in assets/fonts).

== Installation ==

1. Download yanagi-hygiene.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/yanagi-hygiene.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Yanagi Hygiene.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, sample notes with categories and tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice. The theme works without WooCommerce.

The company, its people, address, telephone number and prices are fictional.
