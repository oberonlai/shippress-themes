# Yanagi Hygiene

Yanagi Hygiene is a calm, documentary landing theme for commercial pest-control and hygiene firms. A full-bleed ceiling-void photograph ends in a white commercial skyline and a twelve-month rail with four visit markers, followed by a building cross-section with plus pills, a sticky photograph beside four timed chapters, a parallax band, a framed logbook panel, fees and a pentagon request tab. Manrope and Source Sans 3. Sample content in English.
