Tayori Nursing is a clean, tranquil WordPress theme designed for local home-visit nursing and rehabilitation services. Built with high-key photography, clear care-plan steps, and transparent fee tables, it presents everyday healthcare with calm clarity. Features include responsive sticky layouts, accessible typography, and dedicated templates for visits, staff profiles, and home-care stories.

== Description ==

A WordPress block theme from ShipPress. Pebble-masked photographs scattered on warm grey, a celadon wave, a grey-to-ink statement, a sticky heading beside white cards, a morning round, a care plan and fees. See README.md for the design notes and brand.md for the fictional nursing service the sample content is written for. Fonts: Manrope and Public Sans (SIL Open Font License), with Noto Sans TC and Noto Sans JP subsets for Chinese and Japanese headings.

== Installation ==

1. Download tayori-nursing.zip from the theme's release.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Tayori Nursing.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php, driven by demo-content.json): it creates its pages with all their text and images, sample posts with categories and tags, the menu, and sets the front page and posts page. It never changes or deletes existing content, and running it again only adds what is missing. If the automatic setup did not run, use the "Import demo content" button shown in wp-admin, or run: wp shippress demo-import
