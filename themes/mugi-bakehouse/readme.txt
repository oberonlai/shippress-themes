Mugi Bakehouse is an editorial-magazine block theme crafted for neighbourhood bakeries, artisan food stores, and community kitchens. Built around a disciplined day-schedule rhythm and refined serif typography, it features dual-frame hero edge tabs, fixed corner capsules, and slanted price ledger rows. It functions fully as a quiet business showcase or paired with WooCommerce for standing loaf orders.

== Description ==

A WordPress block theme from ShipPress. See brand.md for the fictional bakery the sample content is written for. Sample content is imported on activation (inc/demo-import.php, driven by demo-content.json) and never changes or deletes existing content; if it did not run, use the "Import demo content" button in wp-admin or run: wp shippress demo-import

== Installation ==

1. Download mugi-bakehouse.zip from the theme's release.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Mugi Bakehouse.
