Ueki Gardens is a calm, spec-catalogue WordPress theme designed for garden centres, plant nurseries, and botanical stores. Built with clean sans-serif typography, ragged-top image arrangements, and structured index rows, it presents nursery benches, care specifications, and WooCommerce products with quiet clarity. The layout functions seamlessly with or without WooCommerce, keeping domestic plant care front and centre.

== Description ==
Ueki Gardens is a calm, spec-catalogue WordPress theme designed for garden centres, plant nurseries, and botanical stores. Built with clean sans-serif typography, ragged-top image arrangements, and structured index rows, it presents nursery benches, care specifications, and WooCommerce products with quiet clarity. The layout functions seamlessly with or without WooCommerce, keeping domestic plant care front and centre.
