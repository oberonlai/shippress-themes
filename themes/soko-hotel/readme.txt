Soko Hotel is an editorial hospitality WordPress theme designed for a thirty-two room boutique hotel in a restored 1924 brick harbour warehouse on Kessel Quay. Built with classic serif typography, generous letterbox framing, and a quiet documentary aesthetic, it presents rooms, architectural history, dining, and direct reservations with unhurried clarity.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See brand.md for the design notes. Fonts: Gloock (display), Source Sans 3 (text), and Noto Serif TC / Noto Serif JP (zh-TW and ja subsets), all under the SIL Open Font License.

== Installation ==

1. Download soko-hotel.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/soko-hotel.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Soko Hotel.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The hotel, its people, harbour, address, telephone number and prices are fictional.

== Forms ==

The letter in the footer and the Newsletter page use the shared form slot (inc/shippress-forms.php). Without a form plugin they show a real email field and a submit button that opens the visitor's email app with the address; the notice says plainly that the visitor is not subscribed until that message is sent. MailPoet or Mailchimp for WP are used when active. The Contact and Reserve pages show the first Contact Form 7 or WPForms form when one exists, and a mailto button otherwise.
