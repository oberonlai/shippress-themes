# Sokuten Survey

Sokuten Survey is a landing theme for an independent land surveying firm in Brookmere, founded in 2009. The home page walks through the sites a visit suits, the hour on the ground, the published fees and a single request for a visit. English, Traditional Chinese, Japanese, French and German are included, set in Outfit and Source Sans 3, with Noto Sans TC and Noto Sans JP for CJK headings.

## Structure
- `patterns/front-*.php`: the ten home sections (strip, sites, hour, parallax lot, voices, takeaway, fees, notes, FAQ, request band).
- `patterns/head-*.php`, `tpl-*.php`: the header pieces, page heads and the notes list.
- `templates/`: front page, page, single, notes home, archive, category, tag, search, index, 404.
- `inc/i18n/<lang>.php`: the theme strings; `demo-content*.json`: sample content.
- `assets/js/ss-strip.js`: the accordion strip; `assets/sp-scroll.*`: ShipPress scroll effects.
- Photos: `assets/images/` (AI-generated, GPL-2.0-or-later / CC0).

Design notes: `brand.md`, `brand/design-spec.md`, `brand/reference.md`.
