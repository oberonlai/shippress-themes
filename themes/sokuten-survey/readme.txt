Sokuten Survey is a landing theme for an independent land surveying firm in Brookmere, founded in 2009. The home page walks through the sites a visit suits, the hour on the ground, the published fees and a single request for a visit. English, Traditional Chinese, Japanese, French and German are included, set in Outfit and Source Sans 3, with Noto Sans TC and Noto Sans JP for CJK headings.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes, templates and patterns.

== Installation ==

1. Download sokuten-survey.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/sokuten-survey.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Sokuten Survey.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, six notes with two categories and six tags, the menu, and sets the front page and posts page. It never changes or deletes anything you wrote, and running it again creates nothing twice.

The firm, its people, address, telephone number and prices are fictional.
