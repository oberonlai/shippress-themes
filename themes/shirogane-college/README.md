# Shirogane College

Business theme for a veterinary nursing college: a solid pine panel with a hexagon point beside a cross-dissolving set of ward photographs, an audience row of five dotted cells above it and a three-cell booking bar below. Home continues with a sticky-photo training day, a zig-zag honeycomb of six solid course hexagons over a pale triangulated band, a parallax ward band, tutors, student stories, a fee table, thumb-left pickup tiles and an intake letter.

See `brand.md` and `brand/design-spec.md`.

- Fonts: Manrope and Source Sans 3 (OFL-1.1), loaded through `theme.json` fontFace.
- Forms: the intake letter section uses the shared dynamic form block (`inc/shippress-forms.php`).
- Scroll effects: `assets/sp-scroll.css` and `assets/sp-scroll.js` (reveal up, stagger, parallax, count); the hero dissolve is plain CSS keyframes.
