A block theme for a regional solar installation company: a split first screen with an inset portrait, overlapping case circles, white numeral cards and a ruled price list. Merriweather with Source Sans 3.

== Description ==

A WordPress block theme from ShipPress. See README.md for the design notes and patterns, and brand.md for the fictional company the sample content is written for.

== Installation ==

1. Download taiyo-solar-works.zip from the theme's release.
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Taiyo Solar Works.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php, driven by demo-content.json): it creates the home page with all its text and images, sample posts, the menu, and sets the front page and posts page. It never changes or deletes existing content. If the automatic setup did not run, use the "Import demo content" button in wp-admin, or run: wp shippress demo-import

Roof assessments are booked by phone or email; no plugin is needed.
