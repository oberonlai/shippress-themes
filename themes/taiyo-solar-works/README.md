# Taiyo Solar Works

A block theme (type business) for a regional solar installation company. Home page (English) in this release; inner pages and other languages follow.

## Signature
- Split first screen with an inset portrait.
- Two overlapping hairline circles carrying case figures.
- White numeral cards on a grey band; roof-pitch edge.

## Patterns
- `front-assessment`
- `front-close`
- `front-crew`
- `front-featured-case`
- `front-installations`
- `front-notes`
- `front-roofwork`
- `front-services`
- `front-split`

## Fonts
Merriweather and Source Sans 3 (OFL-1.1), bundled as Latin woff2.
