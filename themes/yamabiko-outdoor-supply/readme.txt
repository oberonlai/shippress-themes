A WooCommerce store theme for an independent outdoor and camping gear shop, built as a spec catalogue.

== Description ==
A full-bleed documentary cover with an info bar, a fixed dash index, a dark field-pick chip, an inset photo band under a dark veil, asymmetric masonry product tiles and full-width spec tables. Cool stone ground, ink, one persimmon-tannin accent. Bitter and Karla (SIL OFL 1.1). Works without WooCommerce.
