# Sumika Residences

Block theme for a serviced-apartment house. Home (en): torn-edge photo hero with an ink pill menu in the notch, offset photo pairs with tilted glyph words, sticky house rows, a gliding photo strip, a torn parallax band, rates, arrival list, speech-bubble voices and an ink enquiry band.

Scroll effects: `assets/sp-scroll.css|js` (reveal, stagger, marquee, parallax) — off for reduced motion.

Pages (en): Home, Houses, Rates, About, Enquire. Each inner page repeats the torn-edge photo hero with the ink pill menu, tilted glyph headings and the ink enquiry band. Page patterns: `patterns/page-*.php`; the demo import creates the pages and the Main menu (Houses, Rates, About).

Photos: 16 film-grain photographs in `assets/images` (the home hero is a street-and-house scene upscaled to 1920px). Languages: en only so far; zh-TW, ja, fr, de are still to do.
