== Description ==

Kaigi Centre is a conference centre WordPress theme designed for association congresses, academic symposia, and corporate offsites. Built with Fraunces serif headings, Source Sans 3 typography, and a calm plum palette, it features clear room network listings, transparent hire rates, and documentary storytelling. The layout provides a single-column longform editorial flow, detailed floor plan specifications, and structured event planning schedules. Works without WooCommerce.

Fonts: Fraunces, Source Sans 3, Noto Serif TC and Noto Serif JP (SIL Open Font License 1.1), bundled. Photographs were generated for this theme. The scroll effects (sp-scroll) respect the visitor's reduced-motion setting and stay visible without JavaScript.
