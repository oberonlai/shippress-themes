# Sumibi Yakiniku

Sumibi Yakiniku is a WordPress theme for a charcoal yakiniku grill with set courses and group bookings. A blush gutter frames a low-key photograph window cut at six degrees with a docked white price plate, a dark photo band bleeds from the gutter, pale tan tabs sit over three course cards, and one price table sits side by side with the group rooms and the single way to reserve.
