Toso Paints is a calm, photographic WordPress store theme crafted for bespoke paint and wallpaper shops with dedicated mixing counters. Designed with an asymmetric three-column hero, fine room-elevation hairlines, and structured stock catalogue tables, it presents products and trade services with deliberate restraint. Built for block editing with full WooCommerce support, the theme performs seamlessly with or without an active storefront.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). The home page opens on three equal low-key photograph columns with a hairline room-elevation drawing across the seams and a stacked caps menu at the top left; it continues with a ruled statement band, a range strip with a giant caps marquee, three sticky full-bleed chapters, a stock-list table, offset mixing and order rows, journal rows and a visit close.

== Installation ==

1. Download toso-paints.zip from https://github.com/oberonlai/shippress-themes/releases/download/themes/toso-paints.zip
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Toso Paints.

On activation the theme sets itself up as a ready-to-use website (inc/demo-import.php): it creates its pages with all their text and images, six journal entries with three categories and six tags and the menu, and sets the front page and posts page. It never changes or deletes anything you wrote.

The shop, its products, address, telephone number and prices are fictional.

== Fonts ==
