Minori Seminars is a quiet, single-column WordPress landing theme designed for executive management desks, training institutes, and public leadership seminars. Built with classical serif headings, structured schedule rows, and high-key documentary photography, it guides managers cleanly from introduction to seat reservation. Features full responsiveness, international language support, and refined scroll-linked presentation inspired by traditional Japanese management institutions.

== Description ==

A WordPress block theme from ShipPress (https://github.com/oberonlai/shippress-themes). See README.md for the design notes.

== Installation ==

1. Download minori-seminars.zip from the releases page of https://github.com/oberonlai/shippress-themes
2. In WordPress admin, go to Appearance > Themes > Add New Theme > Upload Theme, choose the zip and click Install Now.
3. Activate Minori Seminars. On activation it creates the home page, one sample story and the menu (inc/demo-import.php).

The seminar desk, its people, address, email address and prices are fictional.
